# Project Midnight art direction references

Section 5 of the online GDD was expanded on 2 October 2026.

Proposed direction: semi-realistic presentation with realistic human proportions and material response, controlled detail, restrained color, and legible gameplay lighting. This is a project proposal, not a verified description of the current game's finished graphics.

## External reference images

Images are inserted from the official PlayStation pages and credited in the document. They are references to lighting, materials, and environmental transformation, not Project Midnight assets.

- Alan Wake 2, forest investigation: https://www.playstation.com/en-us/games/alan-wake-2/
- Alan Wake 2, rundown General Store: same source.
- Silent Hill f, store building in Fog World: https://www.playstation.com/en-us/games/silent-hill-f/

Apply the visual principles to original Thai locations, tropical vegetation, local architecture, and the project's fictional ritual. The reference screenshots are not a license to reuse game assets.
