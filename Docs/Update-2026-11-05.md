# อัปเดตงานมินตรา — 5 พฤศจิกายน 2026

- อัปเดตไฟล์ต้นฉบับ Blender และ `Mintra_Combine_Lowpoly.fbx` เป็นเวอร์ชันที่บันทึกอยู่ล่าสุด ทั้งสองไฟล์อยู่ใน Git LFS
- เพิ่ม Texture export 10 ไฟล์ใน `ArtSource/Mintra/Texture`: Albedo/Transparency, Metallic/Smoothness และ Normal สำหรับ Head, Body และ Hair พร้อม Opacity map สำหรับผม/คิ้วขนาด 4K
- งานต่อจากอัปเดต 2 พฤศจิกายนที่ขึ้น GitHub ก่อนหน้านี้: ปรับไฟล์ Blender, FBX และ Substance Painter ColorPass v02 พร้อมเพิ่มสคริปต์สร้างแผนที่สีม่านตา ตรวจวัตถุตา และตรวจภาพตัวอย่าง
- เพิ่มกฎข้ามไฟล์ `.spp.painter_lock` ซึ่งเป็นไฟล์ล็อกชั่วคราวของ Substance Painter โดยเก็บไฟล์ `.spp` ตัวงานไว้ตามเดิม

รอบนี้เป็นการอัปเดตไฟล์งานอาร์ต ยังไม่ได้แทนโมเดลใน Player Prefab หรือนำ Texture ชุดนี้ไปผูก Material ใน Unity และยังไม่ได้ทดสอบรูปลักษณ์ใน Gameplay
