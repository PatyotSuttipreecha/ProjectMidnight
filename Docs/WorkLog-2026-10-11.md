## Random Item Spawning
- เพิ่มโหมด Random By Type ใน Item Spawn Point พร้อมกลุ่ม ItemSO ที่บันทึกไว้และปุ่มค้นหาจากโปรเจคใน Inspector

- เพิ่มหน้าต่างจัดการจุด Spawn และเมนูสร้างจุดใหม่


## Random Spawn Locations
- เพิ่ม Spawn Chance ต่อจุด และกลุ่มสุ่มเลือกตำแหน่งไม่ซ้ำตาม Points To Select

- เพิ่มเมนูสร้างกลุ่มและ Inspector พร้อม Gizmo เส้นไปจุดลูก


## Spawn Point Notes
- Item Spawn Point ต้องมี Point Note บน GameObject เดียวกันเมื่อเพิ่ม component
- ตั้ง Note ว่างใหม่เป็น Loot และชื่อจุด โดยรักษาข้อมูลหรือ SO ที่ผูกไว้ก่อนแล้ว


## Related Note Data
- เพิ่มความสัมพันธ์ Note Data หลายรายการในข้อมูลกลาง รองรับ Trigger และ Objective บนจุดเดียว
- เปลี่ยนชื่อช่องหลักเป็น Primary Note Data พร้อมปุ่มเปิดข้อมูลที่เกี่ยวข้อง และเตือนรายการว่าง/ซ้ำ/อ้างตัวเอง


## Related Note Viewport Labels
- แสดงประเภทและชื่อ Related Note Data ใต้ label หลักใน Scene View
- เพิ่มการเปิดปิด แสดงเฉพาะเมื่อเลือก และจำกัดจำนวนข้อความเพื่อควบคุมความรก


## Document Pickup Notes
- เพิ่ม Point Note ประเภท Collectible ลงใน DocumentPickup prefab เพื่อให้ instance เดิมและใหม่รับ component จาก prefab
- DocumentPickup ที่เพิ่มผ่าน Add Component มี Point Note อัตโนมัติ และเครื่องมือวางเอกสารเชื่อม Related Document ให้ Note ที่ยังไม่ผูกข้อมูลกลาง


## Note Data Asset Names
- เมื่อแก้ Title ผ่านเครื่องมือ Note หรือแก้ชื่อใน Hierarchy ระบบเปลี่ยนชื่อ asset Note Data ตาม Title ด้วย
- รักษา GUID และ references เดิม กรองอักขระที่ใช้ไม่ได้ และเติมเลขท้ายชื่อเมื่อมี asset ชื่อซ้ำ
- ปุ่ม Sync hierarchy name ซิงก์ชื่อ asset เดิมได้ด้วย การเปลี่ยนชื่อ asset ใน Project โดยตรงยังไม่เปลี่ยน Title

## Fly Cheat
- เพิ่มโหมดบิน F9 และ toggle ใน Cheat Menu F10/Editor พร้อมปรับความเร็ว 1–50 m/s
- WASD ตามทิศกล้อง Space ขึ้น Ctrl ลง Shift เร่งสองเท่า ปิดแรงโน้มถ่วงเฉพาะระหว่างบิน และคง CharacterController collision
- เมื่อปิดบินคืน gravity ด้วยความเร็วตกเริ่มต้นศูนย์ ระหว่างเมนู/Inventory/Timeline หยุด movement ตาม input lock เดิม
- Runtime/Editor คอมไพล์ผ่าน ยังไม่ตรวจการบินในฉากจริง

## Cutscene หลังเก็บ Evidence

## Fade สำหรับ Cutscene จาก Trigger และเอกสาร
- เพิ่ม Use Fade, Fade To Black Duration, Fade From Black Duration และ Fade Color ใน Cutscene Controller
- เฟดมืดก่อนเริ่ม Timeline แล้วเปิดภาพ Cutscene; ก่อนจบเฟดมืดเพื่อคืนกล้องและเปิดภาพ gameplay
- ใช้ร่วมกันผ่าน CutsceneController.Play ทั้ง WorldTrigger และ On Collected ของเอกสาร/Evidence
- ล็อก Input จนเฟดจบ ใช้ unscaled time และล้างหน้าจอเฟดเมื่อปิด component
- Runtime compile ผ่าน ตรวจ 6 checks ใน Unity โปรเจกต์แยกด้วย coroutine แบบ zero duration และ player stub; ยังไม่ได้ตรวจการเฟดตามเวลาในฉากหลัก
