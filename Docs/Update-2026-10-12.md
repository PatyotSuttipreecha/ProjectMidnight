# อัปเดตโปรเจกต์ 12 ตุลาคม 2026

## ระบบศัตรู
- เพิ่ม Patrol แบบรอคำสั่ง StartPatrol และ PausePatrol สำหรับจัดจังหวะ Cutscene
- เพิ่มความเร็ว Chase การชะลอเมื่อเข้าใกล้ และหยุดเตรียมโจมตี
- เพิ่ม Crowd Movement กระจายจุดเข้าหาและรักษาระยะจากศัตรูข้าง ๆ
- เพิ่ม Knockback และ Stagger เมื่อถูกยิง ใช้ร่วมกับ Partial Ragdoll ที่จุดกระสุนโดน
- แก้การสร้าง NavMeshPath ผิด lifecycle และการอ้างอิง Player ที่มี controller อยู่บนลูกของ prefab
- จัดหมวด Enemy Profile/Enemy Lab พร้อม Tooltip ภาษาอังกฤษ
- รวมงานระบบ Enemy Spawn และ Trigger ตรวจศัตรูถูกกำจัด

## Item / Document / Evidence
- เพิ่ม EvidenceSO ใช้ Catalog และ Examine 3D ร่วมกับ Document
- ปรับ Catalog เป็นโมเดลด้านซ้ายและรายการเลื่อนได้ด้านขวา รายละเอียดเปิดแยก
- เพิ่ม On Collected เพื่อเริ่ม Cutscene หลังปิดเอกสารและเก็บสำเร็จ
- เพิ่ม Item Spawn แบบกำหนด/สุ่มชนิด โอกาสเกิด และสุ่มจุดภายในกลุ่ม
- ย้ายข้อมูล Item, Document และ Evidence เข้า Data Folder

## Cutscene และเครื่องมือออกแบบ
- เพิ่ม World Trigger และ Cutscene Controller พร้อมล็อก Input และ Fade ตอนเข้า/ออก
- ปรับ Point Note อ้างอิงข้อมูลส่วนกลางและ Related Notes พร้อมเครื่องมือจัดการ
- เพิ่มการตั้งชื่อ asset ตามโฟลเดอร์และตัวเลือกเปิด/ปิด Point Notes
- เพิ่ม Cheat Menu สำหรับปรับความเร็วและบิน
- แก้การเชื่อม Crosshair กับ Player prefab ข้ามฉาก

## งานฉากและ Assets
- รวมการปรับ Scenes_Gameplay, Timeline, Animation, NavMesh, Prefab, โมเดล/ภาพประกอบ และข้อมูลที่อยู่ใน working tree
- รวมการเปลี่ยนชื่อ Prefab และการย้าย asset พร้อมไฟล์ meta เพื่อรักษา GUID

## การตรวจสอบ
- Compile Runtime และ Editor ผ่าน โดยใช้ reference ของโปรเจกต์ที่ cache ไว้
- ทดสอบ UI และลำดับเก็บเอกสารใน Unity โปรเจกต์แยกผ่าน 20 checks
- ทดสอบ EnemyController ตัวจริงใน Play Mode โปรเจกต์แยกผ่าน 11 checks รวมการโจมตี การแยกตัว และการตั้ง Stagger
- ทดสอบ Cutscene coroutine stages ผ่าน 6 checks
- ชุดทดสอบบางส่วนใช้ PlayerController stub และขับ coroutine ด้วยมือ ยังไม่ได้ยืนยัน gameplay ทั้งฉากหลักหรือ visual ragdoll ทั้งฝูง
