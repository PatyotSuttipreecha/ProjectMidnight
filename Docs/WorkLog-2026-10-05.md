# Work log — 5 October 2026 (Asia/Bangkok)

## Gameplay and editor updates

- Added configurable Shotgun pellets per shell and pellet spread half-angle. One shot consumes one shell; damage applies per pellet. Other weapon types still fire one projectile.
- Added Shotgun controls in System Modification > Armory Lab, with Scene View spread Gizmos and configurable preview distance. The M870 uses eight pellets with a four-degree half-angle.
- Updated projectile travel to use the firing weapon's speed, sweep for collisions immediately, ignore the shooter and other projectiles, and expire after five seconds.
