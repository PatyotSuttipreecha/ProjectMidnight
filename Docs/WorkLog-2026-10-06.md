# บันทึกการพัฒนา — 6 ตุลาคม 2026

- เปลี่ยน Context Menu, ยืนยัน Drop และ Examine เป็น UI Prefab พร้อม serialized references สำหรับแก้หน้าตาใน Edit Mode โดยโค้ดเติมเฉพาะข้อมูลและเชื่อมคำสั่งปุ่ม
- เพิ่ม InventoryPanel.prefab และ GameObject `Inventory Panel` ใน Playground เชื่อมกับ Player แทน InventoryLayout เดิม เพิ่มช่องตัวอย่าง 4×4 ใน Editor และซ่อน Panel เมื่อเริ่มเกม
- เพิ่มปุ่มเปิด Prefab และแสดง/ซ่อน Panel ในแท็บ Inventory / Examine UI ของ Item Configuration พร้อมอัปเดตคู่มือการออกแบบ UI
- ตรวจคอมไพล์ Runtime/Editor ผ่าน และให้ Unity import Prefab ทั้ง 4 ตัวในโปรเจกต์ตรวจสอบแยก เชื่อม view/panel references ครบ ไม่มี missing scripts โดยใช้สคริปต์จำลองเฉพาะสำหรับตรวจ serialization ยังไม่ได้ตรวจการคลิกและภาพจริงใน Play Mode ของเกม

- เพิ่ม System Modification > Item Configuration สำหรับค้นหา/สร้าง/ปรับ ItemSO และดูโมเดลต้นแบบ พร้อมแท็บตั้งค่า Inventory/Examine UI เปิดให้ปรับสี ฟอนต์ ขนาดเมนู และความไวหมุน/ซูมจาก Inspector รองรับ Undo และบันทึกค่าของ asset/Scene

- แยกรายการอาวุธเริ่มต้นออกจากรายการปืนที่ระบบรองรับ ตั้ง Player prefab ให้เริ่มด้วย Pistol เท่านั้น และยังเก็บ Shotgun จากฉากได้
- เพิ่ม System Modification > Player Configuration สำหรับค่าผู้เล่น อาวุธเริ่มต้น ขนาดกระเป๋า และ References รองรับการปรับ Scene/Prefab และ Undo
- เพิ่ม Context Menu ของ Inventory: คลิกขวาแล้วเลือก Equip/Use, Examine, Drop หรือ Close แทนการใช้ของทันที
- แสดงเหตุผลเมื่อคำสั่งใช้ไม่ได้ และถามยืนยันก่อนทิ้งทั้งกอง
- เพิ่มหน้าตรวจไอเทมด้วยภาพ 2D ชื่อ คำอธิบาย ขนาด จำนวน และข้อมูลเฉพาะของยา กระสุน และปืนแต่ละชิ้น
- เพิ่ม Description ใน ItemSO และตัวเลือก Menu Font ใน InventoryUI สำหรับเลือกฟอนต์ที่รองรับภาษาของเนื้อหา

อัปเดต Examine เพิ่มเติม: แสดงโมเดล 3D กลางจอ ลากหมุน ลูกล้อซูม และ Reset view พร้อมตัวเลือก Inspection Prefab / Inspection Rotation ใน ItemSO คัดลอกเฉพาะ Mesh/Material ใช้กล้อง RenderTexture และไฟแยก และคืนทรัพยากรเมื่อปิดหน้าต่าง หากไม่มีโมเดลจะแสดง Icon แทน

การตรวจคอมไพล์ไม่ยืนยันภาพ แสง หรือการคลิกใน Unity Play Mode

- แก้การปล่อยเมาส์หลังหมุนโมเดล Examine แล้วหน้าต่างปิดเอง โดยให้ Preview รับ click/drag ของตัวเอง และปิดการสั่งปิดจากพื้นหลังของหน้า Examine เหลือปุ่ม Close หรือ Esc สำหรับปิด

- ปิด Cinemachine Input Axis Controller ของกล้องผู้เล่นเมื่อเปิด Inventory รวมถึงช่วง Examine และแอนิเมชันลุก คืนสถานะเดิมเมื่อปิดและลุกเสร็จ พร้อมล้างแรงหมุนค้าง โดยเมาส์สำหรับ UI และการหมุนโมเดล 3D ยังทำงาน
