# บันทึกการพัฒนา — 10 ตุลาคม 2026

### ซิงก์ชื่อ Point Note สองทาง
- เพิ่ม PointNoteNameSync ใน Editor: เปลี่ยนชื่อ GameObject ใน Hierarchy แล้วอัปเดต Title; แก้ Title แล้วอัปเดตชื่อเป็น [PointType] Title
- ตัด prefix ประเภทที่รู้จักออกจาก Title รวมรูปแบบเก่าที่มี Status และคง prefix ให้ตรงกับ Point Type ปัจจุบัน
- ใช้ Auto Name In Hierarchy เป็นตัวเปิด/ปิด รองรับจุดใน Scene/Prefab Mode และวัตถุ inactive; ไม่แก้ prefab asset ที่ไม่ได้เปิดและไม่ไล่เปลี่ยนชื่อเดิมตอนโหลด Editor
- รองรับบันทึก scene/prefab overrides และ Undo/Redo ผ่าน baseline; คอมไพล์ Runtime/Editor ผ่านพร้อม warning เดิม ยังไม่ได้ทดสอบการ Rename/Undo แบบโต้ตอบใน Unity จริง

### ย่อรายการ Scene Notes
- รายการฝั่งซ้ายเหลือ Title และ Point Type/Status สองบรรทัด ความสูง 46 แทนการแสดง Hierarchy/Scene path หลายบรรทัด
- รายละเอียดเต็มยังอยู่ใน tooltip และแผงด้านขวา คอมไพล์ Editor ผ่าน ยังไม่ตรวจภาพใน Unity จริง

### เรียง Scene Notes ตามรหัสภารกิจ
- เรียงตาม Mission ID แบบ natural order (M2 ก่อน M10) ภายในกลุ่มให้ Mission มาก่อนแล้วเรียง Objective ID/Title จุดไม่มี Mission ID อยู่ท้ายรายการ
- รายการเรียงใหม่ตามรหัสที่แก้โดยไม่ต้อง Refresh คอมไพล์ Editor ผ่าน

### World Trigger System
- เพิ่ม WorldTrigger เป็น volume BoxCollider/Rigidbody kinematic ตรวจผู้เล่น เข้า/ออก และเรียก On Triggered ผ่าน UnityEvent รองรับ Armed, Trigger Once, cooldown, retry while inside, ResetTrigger และการกัน activation ระหว่างเปิด Inventory/เอกสาร
- รวม Collider หลายชิ้นของผู้เล่นเป็น entry/exit เดียว และจัดการ Collider ถูกปิด/ทำลายโดยไม่ส่ง exit
- เพิ่ม System Modification > Trigger Configuration สร้างจุดใหม่หรือเพิ่มให้จุดเดิม ปรับ volume และ events พร้อม Gizmos
- คอมไพล์ Runtime/Editor ผ่าน และทดสอบ callbacks/state ของสคริปต์จริงใน Unity โปรเจกต์แยก 13 ข้อผ่าน (Player เป็น stub); ยังไม่ตรวจ physics overlap ใน Gameplay จริง ไม่ได้สร้างฉาก/เชื่อม Timeline หรือระงับ input ของ Cutscene อัตโนมัติ

### Trigger อ้างอิง Note Point
- เพิ่ม Note Source ให้ WorldTrigger และ Create Linked Trigger ใน Inspector ของ Trigger Note / Scene Notes สร้าง runtime object แยกและใช้ Note เดิมเป็นข้อมูลหลัก ชื่อและ position/rotation ตาม Note โดยไม่คัดลอก Note/Events
- ตั้ง Activation, Events และขนาด Collider จริงได้จาก Note panel หรือ Trigger Inspector; Add / Link Note สร้าง Note ที่ขาดให้ และมีปุ่มเลือกไปมาระหว่างจุดจริงกับ Note
- เปิด/ปิด Follow Note Placement ได้ ไม่คัดลอก scale; sync ใน Editor ทุก 0.25 วินาทีและ align ครั้งเดียวเมื่อ Awake ไม่ไล่ตาม marker ที่เคลื่อนระหว่างเล่น
- สร้างซ้ำใช้ Trigger เดิม รองรับของเก่าที่ติด Trigger บน Note โดยไม่ล้าง Events ยังไม่ดึง Status/Mission ID/Prerequisite มาเป็นเงื่อนไข Gameplay
- คอมไพล์ผ่าน และทดสอบใน Unity โปรเจกต์แยก 19 ข้อผ่าน รวมสร้าง/เชื่อม/ไม่ซ้ำ/ชื่อและตำแหน่งตาม Note/รักษาขนาด volume/ปิด follow; Player เป็น stub และยังไม่ทดสอบเดินผ่าน Collider ในฉากจริง

### ปรับ Note เป็นคลังข้อมูลทั้งเกม
- แก้แนวทางก่อนหน้า: PointNoteData เป็น SO ข้อมูลหลักของทั้งเกม เก็บชื่อ ประเภท สถานะ เนื้อหา Location/Planned Scene และกราฟ Mission/Prerequisite เป็นการอ้างอิง Data ไม่ใช่ GameObject
- PointNote บนฉาก/Prefab มี Note Data reference พร้อมตำแหน่งและ Gizmos เฉพาะจุด; เลือกข้อมูลเดิมหรือ Create Data from This Note สร้าง asset ใหม่ใน Assets/Data/PointNotes ได้ ข้อมูล shared เปลี่ยนแล้วทุกจุดอ้างอิงตาม
- Scene Notes เปลี่ยนเป็น All Game Data catalog รวมข้อมูลที่ยังไม่วางในฉาก สร้าง Data แยกจากการ Place Note/Trigger พร้อมแก้ข้อมูลส่วนกลางและดู placements ในฉากที่โหลด
- WorldTrigger มี PointNote บน GameObject เดียวกันให้อ้างข้อมูลจาก SO โดยไม่ดึงชื่อ/ตำแหน่งจาก marker ตัวอื่นอีก; Events/Collider/activation ยังเป็นข้อมูล local ไม่เอา UnityEvent ที่อ้างวัตถุฉากลง SO
- เก็บ field เดิมด้วย FormerlySerializedAs เพื่อไม่ทำข้อมูลเดิมหาย เพิ่ม Import Notes from Open Scenes และ Import All Saved Scenes/Prefabs ซึ่งแปลง Note/กราฟเดิมเป็น data assets; ข้ามฉาก dirty และ Prefab Stage ที่เปิดเพื่อรักษางานยังไม่เซฟ
- การแปลงฉากจริงต้องเรียก Import จากหน้าต่างหลัง Unity โหลดสคริปต์ ไม่แก้ฉากหรือ save งานค้างอัตโนมัติ; Location/Planned Scene เป็นการระบุพื้นที่ ไม่ใช่ดัชนี placement ทุกฉากแบบสด
- เพิ่มตัวกรอง Location และ Bind Data to Selected GameObject ให้จัดข้อมูลตามพื้นที่และนำข้อมูลเดิมไปอ้างอิงบนจุดที่เลือกได้
- ทดสอบใน Unity โปรเจกต์แยก 18 ข้อผ่าน: แปลงข้อความ/กราฟเดิมเป็น SO, shared references, ข้อมูลอยู่หลังลบจุด, Trigger มี PointNote และไม่บังคับคัดลอกตำแหน่ง, sync IDs/cycle, โหลด field เก่าจาก prefab, import ฉากที่ยังไม่เปิดและ import ซ้ำไม่สร้าง binding ซ้ำ; Player เป็น stub ยังไม่ตรวจ UI/Gameplay ในฉากจริง

### แยกหน้าที่ Component
- ถอด UI ข้อมูล Note และ field noteSource/followNotePlacement ออกจาก WorldTrigger; ตั้ง SO เฉพาะผ่าน PointNote ซึ่งมีให้อัตโนมัติบน GameObject เดียวกัน
- WorldTrigger เหลือ activation/events/volume และไม่ตั้งชื่อหรือประเภทของ Note; คอมไพล์ Runtime/Editor ผ่าน
- ถอด panel ค่าของ Trigger ออกจาก PointNote Inspector และ Scene Notes ด้วย ตั้งค่า Trigger ผ่าน WorldTrigger/Trigger Configuration เท่านั้น คอมไพล์ Editor ผ่าน

### Cutscene input controller
- เพิ่ม CutsceneController บน GameObject ของ PlayableDirector: Play จับล็อก input ก่อนเล่น, รับ played/stopped, คืนล็อกเมื่อจบ/Stop/Disable และมี On Started/On Finished พร้อม Wrap Mode None เป็นค่าเริ่มต้น
- PlayerController เพิ่ม owner-based input locks กันปลดล็อกข้ามระบบ หยุดเดิน/หมุน/เล็ง/สลับปืน/เปิด Inventory และระงับ Cinemachine camera input; Guns/Interaction ใช้ IsGameplayInputBlocked เดิมร่วมกัน
- ระหว่าง Cutscene ให้ Timeline คุม pose/placement โดยไม่ ApplyGravity/เปลี่ยน animation parameters ทุกเฟรม ปรับการคืนกล้องของ Inventory/เอกสารให้เคารพล็อก Cutscene และจัดการกรณีเริ่ม Timeline ก่อน Player.Start
- Runtime คอมไพล์ผ่าน; ทดสอบ CutsceneController กับ PlayableDirector จริงใน Unity โปรเจกต์แยก 9 ข้อผ่าน (Player เป็น stub และจำลอง lifecycle callbacks ใน Editor); ยังไม่ทดสอบ input กล้อง/ผู้เล่นและการจบ Timeline ตามเวลาจริงใน Gameplay

## Item Spawn Points
- เพิ่มจุด Spawn ไอเทม เลือก ItemSO และจำนวน พร้อมตัวกรองประเภท/ค้นหาใน Inspector
- รองรับสร้างเมื่อเริ่มเกมหรือเรียก Spawn() จาก WorldTrigger พร้อมป้องกันสร้างซ้ำและ Gizmo ตำแหน่ง
- ใช้ PickupItem เดิมสำหรับเก็บเข้ากระเป๋าด้วย F และรองรับ prefab เฉพาะจุด
- เพิ่มคู่มือ Docs/ItemSpawning.md
