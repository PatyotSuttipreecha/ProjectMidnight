# บันทึกการพัฒนา — 8 ตุลาคม 2026

### Description แยกตามประเภทและเส้นลำดับของ Mission
- เพิ่ม Mission Description แยกจาก Objective Description; Inspector และ Scene Notes แสดง Description ตามประเภท Mission/Objective ส่วน Puzzle ใช้ Objective Description และ Note ทั่วไปยังอยู่
- ซ่อนช่องเฉพาะ Objective เช่น Objective ID/Type/Required Count/Optional เมื่อเป็น Mission และเพิ่มคำค้น Mission Description
- เมื่อเลือก GameObject Mission จะแสดงเส้น Prerequisite ของ Objective ที่อ้างในรายการ Objectives ด้วย แม้ปิดเส้นประ Mission membership; ยังคงเคารพการปิด Gizmos/Prerequisite Links และจำนวนเส้นของแต่ละ Objective
- คอมไพล์ Runtime/Editor ผ่านพร้อม warning เดิม ยังไม่ได้ตรวจภาพใน Unity จริง; ข้อมูลยังเป็น authoring metadata

### สรุปอัปเดต GitHub
- แยกคำอธิบาย Mission/Objective และแสดงช่องเฉพาะตามประเภท พร้อมค้นคำอธิบาย Mission ใน Scene Notes
- เลือก Mission แล้วเห็นเส้นลำดับ Prerequisite ของ Objective ในกลุ่ม โดยยังใช้ toggle และจำนวนเส้นของแต่ละจุด
- รวมการปรับข้อมูลจุดและแผนภารกิจใน Scenes_Gameplay, lighting/reflection probe, material และ project/package settings จาก working tree พร้อม AllSkyFree assets
- ตรวจพบตัวอย่างการอ้าง Prerequisite กลับลำดับ: ช่องนี้ต้องใส่ข้อที่ทำก่อนบนจุดถัดไป เช่น 02 อ้าง 01 จึงได้ลูกศร 01 -> 02; ไม่ได้กลับทิศในสคริปต์หรือแก้ข้อมูลฉากอัตโนมัติ
- ตรวจ Runtime/Editor คอมไพล์ผ่านก่อนเผยแพร่ มี warning เดิม ยังไม่ตรวจ Gizmos/หน้าต่างล่าสุดใน Unity จริง และยังไม่ได้เพิ่ม Mission runtime
