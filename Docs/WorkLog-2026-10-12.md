## ปรับการไล่ตามของ Enemy หลายตัว — 2026-10-12
- เดิมทุกตัว SetDestination ไปที่ตำแหน่งผู้เล่นตรงกัน และ Enemy prefab ใช้ avoidancePriority 50 เหมือนกัน
- เพิ่มจุดเข้าหาแบบกระจายมุมคงที่รายตัว ตรวจ NavMesh/path และจำกัดระยะให้ยังโจมตีได้
- จุดเข้าหาที่ใช้ไม่ได้กลับมาไล่ตำแหน่งเดิม; ตอน Search ยังคงใช้ตำแหน่งล่าสุดที่เห็น
- เพิ่ม Spread chase targets, Chase approach radius, Chase repath interval และ Vary avoidance priority ใน Enemy Profile / Enemy Lab
- ไม่แก้จุด Patrol ที่ออกแบบไว้ ทางแคบยังเกิดการเดินต่อแถวได้ตามพื้นที่จริง
- Compile Runtime/Editor ผ่าน ยังไม่ได้ทดสอบฝูงศัตรูใน Play Mode ฉากหลัก

## แก้การคำนวณปลายทาง Chase ซ้ำ
- ไม่ขอเส้นทางใหม่ระหว่าง pathPending และไม่เรียก SetPath ทับทุก interval
- ใช้ SetDestination เมื่อปลายทางเปลี่ยนเกิน 0.2 หน่วย หรือไม่มี path เท่านั้น
- Serialize สถานะ IsPatrolRunning เพื่อรักษาสถานะรอคำสั่งระหว่าง reload
- เพิ่ม label Waiting for StartPatrol / Missing Profile / Agent not on NavMesh แยกจาก Idle
- พบ scene override ปิด startPatrolOnStart ใน Enemy หนึ่ง instance; คงค่าที่ผู้ใช้ตั้งไว้
- Compile ผ่านก่อนปรับข้อความ label; ยังไม่ได้ทดสอบ Play Mode ฉากหลัก

## แก้ Enemy ไล่ตำแหน่งราก Player และโจมตีไม่โดน
- ตรวจ Player prefab พบ Tag Player อยู่ที่ parent ซึ่งไม่มี PlayerController; controller อยู่บน child ที่เคลื่อนด้วย CharacterController
- แก้ Start/AlertTo ให้ resolve target ไปยัง transform ของ PlayerController และหา damage receiver จาก controller จริง
- ตอนเข้าใกล้ผู้เล่นใช้ปลายทางตรงตัวแทนจุด offset และไม่บังคับมุมมอง Patrol ในการโจมตีศัตรูที่ Alert แล้ว (ยังตรวจระยะและสิ่งกีดขวาง)
- การกระจายจุดใช้เฉพาะระยะไกลและเข้าจากฝั่งศัตรูแทนการวนไปยังมุมโลกตายตัว
- Runtime compile ผ่าน; ยังไม่ได้ยืนยัน NavMesh/ฝูงศัตรูใน Play Mode ฉากหลัก

## แก้ Exception ที่ขัดการสร้าง Enemy (ยืนยันจาก Editor.log)
- Editor.log พบ UnityException InitializeNavMeshPath is not allowed ... constructor/field initializer ที่ EnemyController ตามด้วย NullReference ใน ApplyPhysicsMass
- สาเหตุจาก approachPath = new NavMeshPath ใน field initializer ที่เพิ่มในการกระจายจุดไล่ตาม ทำให้ constructor ไม่สร้าง field ถัดไปครบ
- ย้ายการสร้าง path ไป Awake และเพิ่ม fallback ใน SetChaseDestination
- ทดสอบ production EnemyController และ dependency ฟิสิกส์ใน Unity โปรเจกต์แยกผ่าน 5 checks: constructor, Awake/path, target child, attack range และ damage
- PlayerController ใช้ stub; coroutine attack ขับด้วยมือ ยังไม่ได้ยืนยันฝูงศัตรูในฉากหลัก

## แยก Enemy จากเพื่อนระหว่างเดิน
- เพิ่ม Separate Nearby Enemies, Separation Radius และ Separation Speed ใน EnemyDataSO/Enemy Lab
- เก็บ registry ของ Enemy ที่ active และคำนวณแรงแยกแนวราบจากเพื่อนใกล้ ๆ ในฉากเดียวกัน ไม่ผลักข้ามชั้น
- ใช้ NavMeshAgent.Move และ Raycast ขอบ NavMesh แทนการย้าย Transform หรือ reset เส้นทาง
- จำกัดความเร็วแรงแยกตามความเร็ว Agent ไม่ผลักตัวโจมตี/ตาย/รอคำสั่ง; กรณีซ้อนจุดเดียวใช้ทิศคู่ตรงข้ามคงที่เพื่อลด jitter
- Compile Runtime/Editor ผ่าน ทดสอบใน Play Mode โปรเจกต์แยกผ่าน 7 checks รวมแรงแยกบน NavMesh และการไม่ขยับตัว Pause
- Player ใช้ stub, attack coroutine และ separation timestep เรียกด้วยมือในชุดทดสอบ; ยังไม่ได้ตรวจฝูงศัตรูในฉากหลัก

## Enemy เร่งไล่และชะลอก่อนโจมตี
- เพิ่ม Chase Speed, Close Approach Speed, Chase Slowdown Distance, Speed Change Rate และ Attack Preparation Time ใน Enemy Profile/Enemy Lab
- ไล่เมื่อมองเห็นผู้เล่นเร็วขึ้น และผสมความเร็วตามระยะเข้าหา เปลี่ยนความเร็วด้วย MoveTowards ร่วมกับ NavMesh acceleration
- หยุด Idle ก่อน attack animation แยก preparation จาก hit windup และตรวจระยะซ้ำเพื่อยกเลิกการตีเมื่อผู้เล่นหนีออกไป
- Run Animation เป็น optional Animator state หากไม่มีจะใช้ท่า Walk เดิม ยังไม่สร้าง BlendTree หรือ clip วิ่งใหม่
- Compile Runtime/Editor ผ่าน ทดสอบ production EnemyController ใน Play Mode โปรเจกต์แยกผ่าน 8 checks รวม preparation stop/damage/separation; Player ใช้ stub และ coroutine ขับด้วยมือ

## จัดหมวด Movement และเพิ่ม Tooltip
- แยก Patrol Movement, Chase Movement, Navigation Steering, Crowd Approach, Crowd Separation และ Attack Range/Timing ใน EnemyDataSO
- เพิ่ม Tooltip ภาษาอังกฤษอธิบายหน่วย ข้อจำกัด และความสัมพันธ์ระหว่างความเร็ว ระยะหยุด ระยะโจมตี และเวลารอ
- จัดหมวดช่องใหม่ใน Enemy Lab และส่ง SerializedProperty.tooltip เข้าป้าย GUIContent เพื่อแสดงคำอธิบายเมื่อชี้เมาส์
- คงชื่อ field และค่า default เดิม ข้อมูล SO ที่ตั้งไว้ไม่ต้องย้าย
- Compile Runtime/Editor ผ่าน

## Bullet Hit Reaction: Knockback และ Stagger
- ใช้ partial ragdoll เดิมส่ง impulse ณ จุดกระสุนโดนไปยังกระดูก/hitbox ที่รับแรง
- เพิ่ม Hit Knockback Distance, Duration และ Hit Stagger Duration ใน Enemy Profile/Enemy Lab พร้อม Tooltip
- เมื่อศัตรูมีชีวิตและเปิด hit reaction จะหยุด AI ชั่วครู่ ถอยตามทิศกระสุนผ่าน NavMeshAgent.Move และจำกัดขอบ NavMesh
- ยกเลิก attack coroutine ที่กำลังเตรียมหรือโจมตี ป้องกัน damage ระหว่างเสียจังหวะ และคืนการเดินหลังเวลาครบ
- Pause/Disable ล้าง knockback และ stagger; ไม่ผลักรากตัวที่รอคำสั่ง Cutscene
- Compile Runtime/Editor ผ่าน ทดสอบโปรเจกต์แยกผ่าน 11 checks รวม stagger scheduling และ pause cleanup; ยังไม่ได้ตรวจ visual ragdoll/แรงถอยจริงในฉากหลัก
