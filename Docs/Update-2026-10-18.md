# รายการอัปเดต — 18 ตุลาคม 2026

## Enemy Combat
- แยกสิทธิ์เคลื่อนที่เข้ากดดัน (Rush Slot) กับสิทธิ์เริ่มโจมตี (Combat Turn) และจัดจังหวะเติมตัวแทน/เริ่มท่าร่วมกันตามผู้เล่นเป้าหมาย
- ปรับวงจรเข้าประชิด เดินกดดัน และ Charge พร้อมช่วงเตรียม พุ่ง โจมตี และ Recovery; Charge ที่โดนสามารถล็อกผู้เล่นและพักสิทธิ์โจมตีของกลุ่มชั่วคราว
- ยกเลิกการพักทั้งฝูงด้วย Escape: ผู้เล่นวิ่งไม่ทำให้ทุกตัวผ่อนแรงหรือแจกสิทธิ์ใหม่พร้อมกันอีกต่อไป
- แยก physical hit feedback จาก Action Break: ยิงโดนยังมีการตอบสนองกระดูก แต่ไม่หยุดท่าหรือเสียสิทธิ์ทันทีทุกนัด; Break ใช้ impact สะสมหรือโอกาส Critical พร้อมช่วงต้านทานหลัง Break
- กระสุนหลายเม็ดในหนึ่งนัดคิด impact/สุ่ม Critical ครั้งเดียวต่อศัตรู ส่วน HP damage ของแต่ละเม็ดยังคงทำงาน
- เก็บค่าที่ผู้ใช้ปรับในฉากและ Profile ไว้ รวม Rush Slot 2 และ Machete Chase Slowdown Distance 4 เมตร; ไม่เพิ่มระยะฟันตามข้อเสนอที่ยังไม่ได้อนุมัติ

## Gameplay Debug และการเกิดศัตรู
- ป้าย State กระชับติดตัว พร้อมแสดงสิทธิ์กดดัน/โจมตี รายละเอียดตัวที่โฟกัส และค่า impact
- Cheat Menu > Enemy Debug > Show Melee Attack Range แสดงวงระยะ มุมโจมตี และตัวเลข; เลือกจำนวนตัวใกล้ที่สุดได้ เปิดแยกจากป้าย State
- วงระยะเป็นแนวเทียบแนวนอนของการตรวจระยะสามมิติ ไม่ใช่ collider อาวุธ และยังต้องผ่านเงื่อนไขสายตา มุม เวลา และการป้องกันผู้เล่น
- Spawn แบบต่อเนื่องรองรับรอเกิดนอกกรอบกล้อง ตรวจขอบเขตร่างกาย ไม่ใช่จุดศูนย์กลางอย่างเดียว; ย้าย scheduled spawn ไป LateUpdate
- เพิ่มอายุ/แหล่งที่มาของศัตรูและการตรวจ root jump เพื่อแยกเกิดใหม่กับการย้ายตำแหน่ง; ปรับ Animator/SkinnedMesh ให้ไม่ค้างภาพเมื่ออยู่นอกกล้อง
- การตรวจคลิปเก่ายังไม่ยืนยันสาเหตุการปรากฏทันทีของทุกตัว ต้องใช้ข้อมูล runtime ใหม่ตรวจต่อ

## Player, Weapons และ Tools
- เพิ่ม HUD เลือดวงกลม อาวุธที่ถือและกระสุน ใช้ Prefab ปรับหน้าตาได้ พร้อมเลิกแสดง Ammo HUD เดิมซ้ำ
- เพิ่ม Cheat กระสุนไม่จำกัดและเครื่องมือเสก Item พร้อมจัดหน้าต่าง System Modification/Enemy Lab และหน้าตั้งค่าที่เกี่ยวข้อง
- Damage มาจาก Weapon Stat ของปืน; ค่า 0 ไม่สุ่ม damage ทดแทนอีกต่อไป
- Crosshair ฉายขอบเขต spread จากทิศยิง/FOV/ระยะเป้าหมายให้สอดคล้องกับการยิงจริง
- สร้าง Patrol Route จาก Spawn Point ให้เป็น child และ assign อัตโนมัติ; Shift-click เพิ่มจุดใต้ Route คงตำแหน่งโลกเมื่อสร้าง ปรับ Transform ได้ และรองรับ Undo/Prefab reference override
- Route เก่าหรือ Route ที่แชร์อยู่ไม่ถูกย้ายให้อัตโนมัติ

## ไฟล์ประกอบและการตรวจ
- รวมการปรับ Scene, Prefab, Profile, Animator, การย้ายไฟล์แอนิเมชันพร้อม meta และไฟล์อาร์ตที่บันทึกอยู่ใน workspace
- เพิ่มคู่มือ Charge, Action Break, HUD, damage/spread, visibility diagnostics และแผนภาพพฤติกรรมภาษาไทย/Combat
- ตรวจ Compile Runtime และ Editor ผ่าน; ชุดทดสอบแยกก่อนหน้า Combat 325 checks และ Weapon 4523 checks ผ่าน ส่วน HUD ผ่าน 15 checks ในการสร้างครั้งก่อน
- ชุดทดสอบ Combat/HUD ใช้ Player บางส่วนเป็นตัวจำลอง จึงไม่ยืนยันภาพ แอนิเมชัน และสมดุลของฉากหลักทั้งหมด; การจัด child Route และวงระยะล่าสุดตรวจ Compile แล้ว ยังไม่ได้ทำ UI/Scene interaction test ใน Unity หลัก
