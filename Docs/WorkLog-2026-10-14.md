# Dev log — 14 ตุลาคม 2026

## รอบต่อมา — ปรับการกดดันและการไล่ต้อน

แยกการไล่เข้าพื้นที่ (Chase), การเข้าประชิดเมื่อได้สิทธิ์ (Approach) และการเดินวนรอสิทธิ์ (Pressure) ให้ชัดเจน สาเหตุที่ Pressure สลับไป Search คือ NavMesh หมุนตามทิศทางเดินจนเป้าหมายหลุดจากมุมมอง จึงแยกการหันมองผู้เล่นออกจากทิศเดิน และคงการตรวจระยะกับกำแพงเพื่อให้ Search เกิดจากการขาดการมองเห็นจริง

วง Pressure ใช้ค่าเริ่มต้น 1.8 เมตร ไม่ผูกกับระยะอาวุธ เพื่อไม่ให้ตัวขว้างหินต้องยืนไกลเกินไป ตัวที่รอนานถอนกลับ Patrol ได้ แต่โหมด Aggressive จะไล่ต้อนต่อเนื่องโดยไม่ Search หรือถอนจากการรอ การสั่งทั้งกลุ่มใช้ EnemyGroup ซึ่งจำสถานะและส่งให้ศัตรูที่ Spawn ใหม่ โดยไม่เขียนทับ SO และไม่ปลุกตัวที่พักสำหรับคัทซีน

เพิ่ม ChaseBurst เพื่อให้มีจังหวะเดินสลับเร่ง แยกช่วงเวลาแบบสุ่มต่อตัวและคงการเปลี่ยนความเร็วตาม Speed Change Rate/Agent acceleration การเข้า Approach ใกล้ตัวและ Pressure จะหยุด Boost เครื่องมือปรับค่ารองรับ Profile แบบเดี่ยว รวมถึงแก้ Weapon Module ในหน้าเดียวกัน ส่วน Cheat Menu เพิ่มเลือดไม่จำกัดและรวมเครื่องมือทดสอบไว้เป็นหมวด

ผลทดสอบล่าสุดก่อน commit: Runtime/Editor compile ผ่าน และ Play Mode แยกผ่าน 59 checks โดยใช้ AI/Group/Spawn/Module จริงกับ PlayerController damage stub การดูภาพเดินวน ท่า Run การออกจากคัทซีน และการเล่นจริงทั้งฉากยังต้องตรวจต่อ รวมงานจัดโฟลเดอร์ Prefab/อาวุธต้นแบบ/Flowchart และฉากที่อยู่ใน working tree ไว้ในการอัปเดตนี้ด้วย

รอบนี้รวมงานระบบต่อสู้ The Lost งานออกแบบพฤติกรรม และต้นแบบตัวละครขึ้น GitHub เพื่อเก็บจุดที่สามารถกลับมาทำต่อได้

แนวทางระบบคือใช้พฤติกรรมพื้นฐานร่วมกัน แล้วให้อาวุธกำหนดระยะ ความเสียหาย และเวลาเตรียม/โจมตี/พัก เมื่ออาวุธหลุดหรือใช้หินหมด ศัตรูจะกลับไปใช้ฐานมือเปล่า การแบ่งสิทธิ์โจมตีช่วยควบคุมแรงกดดันจากฝูง ขณะที่ผลเผาไหม้และการรั้งมีสถานะของผู้เล่นแยกจากข้อมูล Profile

งานภาพมีโมเดล 6 รูปแบบและ Rig Generic ทดลองพร้อม 7 คลิป เพื่อประเมินรูปร่างและการเคลื่อนไหวก่อนทำงานแอนิเมชันเต็ม ส่วน Flowchart เก็บทั้งภาพรวมพฤติกรรมและความสัมพันธ์ของการทำงานกลุ่มไว้ในไฟล์ Draw.io ที่แก้ไขต่อได้

ผลตรวจที่มีอยู่: ระบบ Lost ผ่าน 41 checks และ Group Combat ผ่าน 10 checks ใน Play Mode แยก โดยใช้ตัวรับ Damage จำลอง; Runtime/Editor compile ผ่าน ส่วน Rig ตรวจ Avatar และ sample การเคลื่อนไหวผ่าน ไม่ถือเป็นการยืนยันภาพและสมดุลการเล่นในฉากหลัก

งานถัดไปควรเชื่อมโมเดลกับศัตรูจริง ตรวจความเข้ากันได้ของ Rig/Ragdoll ใส่ท่าโจมตีแต่ละอาวุธ และทดลองจังหวะการเข้าประชิดของฝูงในฉากจริง รายการไฟล์และรายละเอียดอัปเดตอยู่ใน Update-2026-10-14.md
