# บันทึกการพัฒนา — 7 ตุลาคม 2026

- เพิ่มระบบเอกสาร Side Story แยกจาก Inventory: DocumentSO, DocumentCollection, DocumentPickup และ UI Prefab สำหรับหมุน/ซูมโมเดล เปิดอ่านหลายหน้า เลื่อนข้อความ และกลับ/ปิดหน้าต่าง
- เพิ่มปุ่ม Documents ใน Inventory Panel พร้อมเอกสารตัวอย่างสองหน้าและจุดเก็บด้วย E ใกล้ผู้เล่นใน Playground เอกสารไม่ใช้ช่องกระเป๋าและไม่เก็บซ้ำ
- เพิ่ม System Modification > Document Configuration สำหรับสร้าง/แก้ข้อมูล วางจุดเก็บ และเพิ่มเข้า Catalog พร้อมตรวจรหัสซ้ำ สถานะเก็บ/อ่านรองรับ CaptureState/RestoreState เพื่อเชื่อม Save/Load แต่ยังไม่บันทึกลงไฟล์อัตโนมัติ
- ตรวจคอมไพล์ Runtime/Editor ผ่าน ทดสอบ DocumentCollection/DocumentLibraryUI จริงในโปรเจกต์แยก: เก็บซ้ำไม่ได้ สถานะอ่านถูกต้อง ส่ง/รับ JSON SaveState ได้ เปลี่ยนหน้า กลับดูโมเดล ปิดหน้าต่าง และ bindings ของจุดเก็บ/ปุ่มครบ ตรวจภาพหน้าโมเดลและหน้าอ่านพร้อมข้อความ TMP แล้ว ยังไม่ได้เดินเก็บเอกสารใน Playground Play Mode จริง

- พบสาเหตุจริงของภาพ Examine หายหลังตรวจทั้งหน้าต่าง: RawImage ใน ItemExamine.prefab ไม่มี serializedVersion ของ Rect ทำให้ UV โหลดเป็น 0×0 และอ่านเพียงพิกเซลโปร่งใสมุมภาพ แก้เป็น Rect serializedVersion 2 ขนาด 1×1 และคืนค่า UV เมื่อพบ overrides เก่าที่มีขนาดศูนย์ การทดสอบ RenderTexture อย่างเดียวก่อนหน้านี้ไม่ตรวจพบปัญหานี้

- ปรับกล้อง Preview ให้เรนเดอร์เข้า RenderTexture โดยตรงด้วย URP SingleCameraRequest ตอนเปิดและใน LateUpdate ปิดการเรนเดอร์อัตโนมัติเพื่อไม่เรนเดอร์ซ้ำ และปิด Occlusion Culling สำหรับฉากโมเดลแยก การปรับกล้องครั้งนี้ไม่แก้สาเหตุหลัก ซึ่งภายหลังพบว่าเป็นค่า UV ของ RawImage
- คัดลอกเฉพาะ Renderer ที่เปิดใช้งาน เพื่อไม่แสดงโมเดล placeholder ที่ถูกซ่อนไว้ใน Weapon Prefab
- ทดสอบสคริปต์จริงกับ Pistol Prefab และ PC URP Renderer ในโปรเจกต์แยก ยืนยันว่ามีภาพโมเดลใน RenderTexture โดยสคริปต์ทดสอบไม่ต้องสั่ง render แทน ยังไม่ได้ทดสอบการเปิดกระเป๋าและการคลิกใน Playground จริง
- หลังแก้ UV ตรวจว่า Unity โหลดค่าเป็น 1×1 ตั้งแต่ก่อน Initialize และเรนเดอร์ Canvas ของ Examine ทั้งหน้า เห็นโมเดล Pistol แสดงผ่าน RawImage แล้ว เก็บภาพผลตรวจใน Library/Glock19BaseValidation/inspection-full-ui.png

### เพิ่มหน้าต่างจัดการ Document
- ขยาย System Modification > Document Configuration เป็นรายการเอกสารพร้อมค้นหา และแยกแท็บข้อมูล / หน้าเอกสาร / โมเดล 3D / ฉากและ UI
- เพิ่มการสร้างสำเนาที่มีรหัสเฉพาะ แก้เนื้อหาทีละหน้า จัดลำดับหน้า และพรีวิว Asset โมเดล
- เพิ่มทางลัดสร้าง Document System, ลงทะเบียน Catalog, วาง Pickup และเปิด Prefab สำหรับออกแบบ UI
- ตรวจคอมไพล์ Editor scripts ผ่าน มีเฉพาะ warning เดิมของไฟล์อื่น ยังไม่ได้ตรวจหน้าต่างใหม่แบบโต้ตอบใน Unity Editor
