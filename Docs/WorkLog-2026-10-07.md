- ปรับกล้อง Preview ให้เรนเดอร์เข้า RenderTexture โดยตรงด้วย URP SingleCameraRequest ตอนเปิดและใน LateUpdate ปิดการเรนเดอร์อัตโนมัติเพื่อไม่เรนเดอร์ซ้ำ และปิด Occlusion Culling สำหรับฉากโมเดลแยก การปรับกล้องครั้งนี้ไม่แก้สาเหตุหลัก ซึ่งภายหลังพบว่าเป็นค่า UV ของ RawImage
- คัดลอกเฉพาะ Renderer ที่เปิดใช้งาน เพื่อไม่แสดงโมเดล placeholder ที่ถูกซ่อนไว้ใน Weapon Prefab
- ทดสอบสคริปต์จริงกับ Pistol Prefab และ PC URP Renderer ในโปรเจกต์แยก ยืนยันว่ามีภาพโมเดลใน RenderTexture โดยสคริปต์ทดสอบไม่ต้องสั่ง render แทน ยังไม่ได้ทดสอบการเปิดกระเป๋าและการคลิกใน Playground จริง
- หลังแก้ UV ตรวจว่า Unity โหลดค่าเป็น 1×1 ตั้งแต่ก่อน Initialize และเรนเดอร์ Canvas ของ Examine ทั้งหน้า เห็นโมเดล Pistol แสดงผ่าน RawImage แล้ว เก็บภาพผลตรวจใน Library/Glock19BaseValidation/inspection-full-ui.png

### แก้ Player ลอยหลังเพิ่ม Rigidbody
- พบ Player prefab มี CharacterController และ CapsuleCollider ขนาดเดียวกัน ร่วมกับ Rigidbody Dynamic; ระบบเดินยังใช้ CharacterController.Move
- ตั้ง Rigidbody เป็น Kinematic และปิด Use Gravity ปิด CapsuleCollider แบบ solid ที่ซ้อนใน prefab และตั้งค่าเดียวกันเมื่อ Awake สำหรับ Scene overrides
- เพิ่มแรงโน้มถ่วงผ่าน CharacterController รวมช่วงเปิด Inventory ให้กลับลงพื้นได้
- คอมไพล์ Runtime ผ่าน ยังไม่ยืนยันการเดิน/ชนจริงใน Playground Play Mode

### ทดลอง Foot Grounding
- พบ LFIK/RFIK และ Target/Hint เดิมใน Player แต่ weight เท้าและ IKBone เป็น 0; คง Rig เดิมเพื่อไม่กระทบคลิปท่านั่ง
- เพิ่ม PlayerFootGrounding บน Humanoid เดิม เปิด Base Layer IK Pass ตรวจผิว ปรับเท้า/สะโพกแบบ smooth พร้อม Gizmos และแท็บ Foot IK ใน Player Configuration
- ปิดผลเมื่อ Inventory เปิด/ผู้เล่นตาย/ไม่ติดพื้น ไม่แก้ Target เดิม; การลด IK ช่วงก้าวใช้ความสูงเท้า ยังไม่มี contact curves หรือ foot planting
- คอมไพล์ Runtime/Editor ผ่าน ยังต้องทดสอบภาพจริงและจูนกับแอนิเมชันใน Playground

### ยกเลิก Foot Grounding รุ่นทดลอง
- ถอด PlayerFootGrounding และแท็บ Foot IK ที่เพิ่งเพิ่มตามคำขอผู้ใช้หลังพบปัญหา
- คืน Base Layer IK Pass เป็น 0 และถอด component จาก Player prefab โดยเก็บ LFIK/RFIK, Target/Hint และ Rig เดิมไว้

### ตรวจอาการเดินกระตุก
- พบ Rigidbody Player ยังใช้ Interpolate แม้เปลี่ยนเป็น Kinematic และเดิน/หมุนด้วย CharacterController ใน Update เป็นจุดเสี่ยงที่ตกค้างจากการแก้ Rigidbody ครั้งก่อน
- ปิด Rigidbody interpolation ใน Prefab และ Awake ให้ตรงกับการขยับ Transform และตั้ง CinemachineBrain ของกล้องหลักเป็น LateUpdate ให้ตามหลัง Update
- ตรวจจากโค้ดและค่าที่บันทึก พร้อมคอมไพล์ Runtime ผ่าน ยังไม่ยืนยันสาเหตุด้วยการวัดตำแหน่งใน Play Mode จึงต้องลองเดินใน Playground หลังเข้า Play ใหม่

### Central Interaction
- เพิ่ม PlayerInteraction / IWorldInteractable รวมเป้าหมาย ปุ่ม F และข้อความสำหรับ Pickup, เอกสาร และประตู เลือกได้ครั้งละหนึ่งวัตถุ ตรวจระยะ/กล้อง/สิ่งกีดขวาง
- ถอด input/ข้อความแยกของวัตถุเดิม; เปลี่ยนเกณฑ์ Pickup/เอกสารจาก trigger overlap เป็นระยะและตำแหน่งบนจอ ประตูยังต้องเล็ง Collider
- เชื่อม Player prefab และ startup fallback เพิ่มแท็บ Interaction ใน Player Configuration พร้อม TMP prompt แบบ optional
- คอมไพล์ Runtime/Editor ผ่าน; Unity โปรเจกต์แยกทดสอบ selector ด้วยวัตถุจำลอง 7 ข้อผ่าน (F, เล็งก่อน, pickup fallback, กำแพง, Inventory, ตาย, นอกระยะ) ยังไม่ตรวจทุก Prefab ใน Playground จริง

### เปิดเอกสารก่อนเก็บ
- Document Pickup เปิด Examine ด้วย F ก่อนเก็บ และ commit collected/read เมื่อผู้เล่นปิดหน้าต่าง ไม่ commit เมื่อ host ถูก Disable
- ใช้ UI Prefab เดิมบน host แยกจาก Inventory พร้อมระงับ input เดิน/กล้อง/ปืน/Interaction แล้วคืนเมื่อปิด
- คอมไพล์ Runtime/Editor ผ่าน ทดสอบลำดับเปิดก่อนเก็บ/read pending/close commit/input release/forced cancellation ใน Unity โปรเจกต์แยกผ่าน (Player modal เป็น stub); ยังไม่ทดสอบ input กล้อง/ปืนและฉาก Playground จริง

### Point Note / Scene Notes
- เพิ่ม PointNote สำหรับติด Note กับ GameObject หรือจุดในฉาก/Prefab มีชื่อ ข้อความ Category/Tags และสถานะ Info/Todo/Issue/Done พร้อม Gizmos
- เพิ่ม System Modification > Scene Notes ค้นในฉากที่เปิดหรือ Prefab ตามโฟลเดอร์ ดูพิกัด/Hierarchy กรองข้อความและสถานะ และเลือก/Frame/Open Prefab
- รองรับแก้ข้อมูลในฉากด้วย Undo; ข้อมูล Prefab asset อ่านอย่างเดียวในรายการและแก้ผ่าน Prefab Mode เพื่อรักษา overrides
- คอมไพล์ Runtime/Editor ผ่าน ยังไม่ทดสอบหน้าต่างแบบโต้ตอบจริง; ไม่ค้น Scene asset ที่ยังไม่เปิด

### ขยายประเภท Point Note

- คอมไพล์ Runtime/Editor ผ่าน ยังไม่ตรวจภาพหน้าต่างและ Gizmos ใน Editor จริง

### แก้รายการ Scene Notes ถูกตัด
- ยกเลิก fixedHeight แบบบรรทัดเดียวที่ติดมาจาก miniButton และคำนวณความสูงตามข้อความ/ความกว้างรายการ เพื่อให้ชื่อ ประเภท สถานะ Hierarchy และ Scene/Prefab path แสดงครบ
- เพิ่ม padding และระยะห่างระหว่างรายการ คอมไพล์ Editor ผ่าน; ยังไม่ตรวจภาพใน Unity จริง

### Mission / Objective relationships
- เพิ่มรายการ Objectives ของ Mission พร้อมจำนวนช่อง/จำนวน Objective ที่ถูกต้อง เชื่อม Mission ID ไปยัง Objective และสร้าง Objective ID ให้เฉพาะช่องที่ว่าง รักษา ID ที่ตั้งเอง
- ตรวจช่องว่าง ชนิดผิด จุดซ้ำ ID ซ้ำและ Mission ID ไม่ตรง; ไม่ sync Objective ที่ถูกอ้างโดยหลาย Mission หรือคนละ Scene/Prefab Stage
- ตั้งชื่อ Hierarchy เป็น [PointType | Status] Title เมื่อแก้ใน Inspector/Scene Notes พร้อมปิด auto name หรือกด sync สำหรับจุดเดิม รองรับ Undo และ prefab overrides
- เส้นประและลูกศรแสดงความสัมพันธ์เฉพาะกลุ่มที่เลือกเป็นค่าเริ่มต้น พร้อม toggle ข้อความ/จำกัดจำนวนเส้น เพื่อไม่ให้ Scene View รก
- คอมไพล์ Runtime/Editor ผ่าน ยังไม่ได้ตรวจการแสดงผล/Undo ใน Unity จริง; เป็นเครื่องมือวางแผน ไม่ใช่ Mission runtime

### ลำดับ Objective
- เพิ่ม Prerequisite Objectives ใน Inspector และ Scene Notes: ว่างคือจุดเริ่ม มีหลายข้อหมายถึงต้องผ่านทุกข้อก่อน พร้อมลูกศรเส้นทึบจากข้อก่อนหน้าไปข้อถัดไป
- ตรวจ self-reference/จุดซ้ำ/ชนิดผิด/คนละฉาก/Mission ID ไม่ตรงและ dependency cycle ทั้งทางตรงและทางอ้อม แสดง validation ที่ Objective และ Mission
- เส้นแสดงเฉพาะจุดที่เลือกและความสัมพันธ์โดยตรงเป็นค่าเริ่มต้น ปรับข้อความ/จำนวนเส้นได้ คอมไพล์ Runtime/Editor ผ่าน ยังไม่ตรวจภาพใน Unity จริง; ยังไม่บังคับลำดับ Gameplay

### ซ่อนข้อมูล Mission ตามประเภทจุด
- Inspector และ Scene Notes แสดง Mission / Objective Design เฉพาะ Mission, Objective และ Puzzle ประเภทอื่นซ่อนช่องโดยยังเก็บข้อมูลเดิมเมื่อเปลี่ยนประเภท
- ปุ่ม sync ของประเภททั่วไปแสดงชื่อ Sync hierarchy name คอมไพล์ Editor ผ่าน

### ลดช่อง Point Note
- ถอด Category และ Tags ออกจาก PointNote/Inspector/Scene Notes และคำค้น เนื่องจากใช้เฉพาะ metadata สำหรับค้นหา ไม่มีระบบ Gameplay อ้างอิง ใช้ Point Type เป็นตัวจัดกลุ่มแทน

### ชื่อ Hierarchy ของ Note
- เปลี่ยนชื่ออัตโนมัติเป็น [PointType] Title โดยตัด Status ออกจากชื่อ GameObject; ช่อง Status และการแสดงสถานะบนป้ายยังคงใช้ติดตามงาน คอมไพล์ Editor ผ่าน
