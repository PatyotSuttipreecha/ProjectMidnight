# Opening Level — ป่าและบ้านร้าง

## แนวคิด
ผู้เล่นตามทางเดินเก่าผ่านป่าไปถึงบ้านร้าง เพื่อหาของที่ช่วยเดินทางต่อ การฝึกเกิดจากการสำรวจและสิ่งของในฉาก เป้าหมายเบื้องต้นคือ “หาที่พักและอุปกรณ์” ก่อนเปลี่ยนเป็น “ค้นหาของที่ใช้ได้ในบ้าน” ไม่เปิดด้วยหน้าจอสอนหลายคำสั่งพร้อมกัน

ระยะเล่นเป้าหมายประมาณ 10–15 นาที เป็นค่าประมาณสำหรับเริ่ม Blockout ต้องจับเวลาจากการเล่นจริง ภาพรวม: จุดเริ่ม → ทางป่า → ทางแยก → จุดเห็นบ้าน → ห้องรับแขก → ครัว → ห้องเก็บของ → ลานหลังบ้าน

## ลำดับพื้นที่และบทเรียน

| พื้นที่ | การจัดฉากและเหตุการณ์ | สิ่งที่ผู้เล่นเรียนรู้ | เงื่อนไขผ่าน |
|---|---|---|---|
| 1. จุดเริ่มในป่า | ทางเปิด ไม่มีศัตรู มีรั้วเก่าและรอยทางนำสายตา | เดินและหมุนกล้อง | เดินพ้นบริเวณเริ่ม ไม่ต้องเดินเหยียบจุดเฉพาะ |
| 2. ทางป่าคดเคี้ยว | โขดหินและต้นไม้บังคับให้เลี้ยว มีช่วงทางกว้างให้ทดลองวิ่ง | ทิศทางการเดินและ Shift เพื่อวิ่ง | ถึงช่วงถัดไป; การวิ่งเป็นการแนะนำ ไม่ใช่ประตูบังคับ |
| 3. ทางแยกสั้น | เส้นหลักมีรั้วและหลังคาบ้านให้เห็นเป็นช่วง ๆ เส้นรองวนกลับพร้อมของตกแต่ง | สำรวจและสังเกตจุดหมาย | เดินถึงจุดเห็นบ้าน ไม่ต้องเก็บของลับ |
| 4. ช่องเปิดหน้าบ้าน | แนวต้นไม้เปิดให้เห็นบ้านทั้งหลัง ใช้หมอกบางและเสียงไม้ลั่น; ประตูเข้าหลักชัดเจน | อ่านพื้นที่และเข้าใกล้จุดสนใจ | เข้าบ้านผ่านระเบียง |
| 5. ห้องรับแขก | โต๊ะข้างประตูมีของชิ้นแรก พื้นที่รอบโต๊ะโล่ง | F เพื่อเก็บของ และ I เปิด Inventory | เก็บของและเปิดดู Inventory อย่างน้อยหนึ่งครั้ง |
| 6. ครัวและมุมสำรวจ | เสบียงหรืออุปกรณ์ที่ระบบรองรับอยู่ มีข้อความบอกตำแหน่งห้องเก็บของ | แยกของใช้กับอุปกรณ์ และทดลองใช้/ติดตั้งตามระบบจริง | ใช้หรือติดตั้งอุปกรณ์หนึ่งอย่าง; ไม่บังคับใช้ยาถ้าสุขภาพเต็ม |
| 7. ห้องเก็บของ | อาวุธและกระสุนวางแยกกันบนโต๊ะ มองเห็นประตูหลังบ้าน | เก็บอาวุธ กระสุน และเลือกช่องอาวุธ | มีอาวุธพร้อมกระสุนและเลือกถือได้ |
| 8. ลานหลังบ้าน | กระป๋องหรือเป้าไม้ 3 ชิ้นอยู่หน้าคันดิน ทิศยิงหันออกจากบ้าน | เมาส์ขวาเล็ง เมาส์ซ้ายยิง R เติมกระสุน และเคลื่อนที่ขณะเล็ง | ยิงโดนเป้าใกล้และกลาง พร้อมเติมกระสุนหนึ่งครั้ง |

ปุ่มอ้างอิงโค้ดปัจจุบัน: Movement ใช้ Horizontal/Vertical, วิ่ง Left Shift, Interact ค่าเริ่มต้น F, Inventory I, ช่องอาวุธ 1–4, เล็งเมาส์ขวา, ยิงเมาส์ซ้าย, Reload R ควรแสดงปุ่มจากค่าที่ตั้งจริงเมื่อทำ UI ไม่ฝังข้อความปุ่มตายตัว

## ผังพื้นที่

ทางป่าเริ่มด้วยเส้นหลักประมาณ 180–240 เมตร แบ่ง 3 ช่วงด้วยแนวต้นไม้ ไม่ให้เห็นปลายทางตั้งแต่ต้น ทางรองยาวประมาณ 20–30 เมตรและวนกลับเส้นหลัก ไม่มีพื้นที่หลงแบบทางแยกหลายชั้น จุดเห็นบ้านอยู่ห่างระเบียงประมาณ 25–35 เมตร

เริ่ม Blockout บ้านชั้นเดียวขนาดประมาณ 14 × 12 เมตร:

- ด้านหน้า: ระเบียง → ห้องรับแขก → โถงกลาง
- ซ้าย: ครัว เปิดเชื่อมโถง
- ขวา: ห้องนอนสำหรับสำรวจเสริม ไม่เป็นเงื่อนไขผ่าน
- ด้านหลัง: ห้องเก็บของ → ประตูออกลานหลังบ้าน
- ลานหลังบ้านประมาณ 15 × 20 เมตร พร้อมคันดินเป็นฉากหลังเป้า

ห้องเก็บของควรเข้าถึงได้จากโถง และมีช่องมองเห็นลานหลังบ้าน เพื่อให้เส้นทางยิงปืนต่อเนื่อง ไม่ต้องเดินย้อนหลายห้อง ประตูกว้างเริ่มประมาณ 1.2–1.4 เมตร ทางเดินประมาณ 1.8–2.2 เมตร แล้วปรับจาก CharacterController และกล้องจริง โดยเฉพาะถ้าใช้กล้องมุมมองบุคคลที่สาม

## บรรยากาศและการนำทาง

เริ่มป่าด้วยเสียงธรรมชาติและแสงที่ยังอ่านเส้นทางได้ เมื่อเข้าใกล้บ้านลดเสียงนก เพิ่มเสียงลมและไม้ลั่น บ้านดูร้างจากใบไม้กอง กระจกแตก เฟอร์นิเจอร์คลุมฝุ่น และรอยน้ำ ไม่ทำทุกห้องมืดจนมองของไม่เห็น

ใช้หลังคาบ้าน รั้ว พื้นทาง และแสงจากช่องหน้าต่างเป็นจุดนำสายตา ของบทเรียนวางบนพื้นผิวที่ไม่รก ให้ผู้เล่นพบจากเส้นทางธรรมชาติ จุดเก็บของแรกต้องอยู่ก่อนแยกห้อง ใช้ Prompt สั้นเพียงบทเรียนปัจจุบัน และซ่อนเมื่อทำสำเร็จ หากผู้เล่นทำได้อยู่แล้วข้ามคำแนะนำซ้ำ

ลานยิงควรดูเหมือนพื้นที่หลังบ้านของเจ้าของเดิม มีเศษกระป๋อง เป้าไม้เก่า และคันดิน แทนการตั้งสนามฝึกใหม่กลางบ้าน ครั้งแรกยังไม่มีศัตรูบังคับ เพื่อให้ผู้เล่นทดลองปุ่มโดยไม่เสียชีวิตระหว่างเรียน

## ทางเลือกเรื่องกุญแจ

สามารถวางกุญแจในครัวเพื่อเปิดแม่กุญแจห้องเก็บของได้ แต่เพิ่มเมื่อระบบกุญแจ/ล็อกพร้อมเท่านั้น Prefab กุญแจและแม่กุญแจที่สร้างไว้เป็นโมเดล ไม่ได้ยืนยันว่ามีกลไกปลดล็อกแล้ว สำหรับ Blockout รุ่นแรกให้ห้องเก็บของเข้าได้ก่อน

## ป้องกันการติดค้าง

- ของบทเรียนจำเป็นต้องเก็บได้แม้ช่องกระเป๋าเต็ม: สำรองช่องหรือมีจุดวางของใกล้กัน
- อย่าให้ผู้เล่นทิ้งอาวุธ/ของสำคัญแล้วติดด่าน; มีทางเก็บกลับหรือทดแทน
- มีกระสุนเติมซ้ำเฉพาะช่วงฝึก ถ้ายิงหมดก่อนโดนเป้า
- จัด Reload ให้แมกกาซีนไม่เต็มและมีกระสุนสำรอง ห้ามผูกกับจำนวนยิงที่คาดว่าผู้เล่นจะทำ
- อาวุธต้องใช้ Prefab ที่มีระบบยิงจริง โมเดล Glock/M870 อย่างเดียวไม่ใช่อาวุธใช้งาน
- ปิดทางออกไกลด้วยสิ่งกีดขวางที่อ่านออก แต่ไม่ล็อกผู้เล่นในห้องฝึก
- บันทึก Checkpoint ก่อนเข้าบ้านและก่อนช่วงยิง เมื่อระบบเซฟพร้อม

## ขอบเขตรุ่นแรก

ทำทางป่า บ้านชั้นเดียว และลานฝึก พร้อมเดิน/วิ่ง เก็บของ Inventory เลือกอาวุธ เล็ง ยิง และเติมกระสุน ยังไม่เพิ่มปริศนาซับซ้อน ศัตรูไล่ล่า หรือบอส จบช่วงเปิดด้วยผู้เล่นพร้อมเดินทางต่อจากทางออกลานหลังบ้าน

## ขั้นตอนทำ Blockout และเกณฑ์ตรวจ

1. ทำพื้น ทางป่า และห้องด้วยรูปทรงพื้นฐาน ตรวจการชนและกล้องก่อนลงรายละเอียด
2. วางของและอาวุธที่ใช้งานได้จริง ตรวจเส้นทางตั้งแต่เริ่มจนจบโดยไม่ใช้คำบอกนอกเกม
3. เพิ่ม Tutorial Trigger ที่ติดตามการกระทำสำเร็จ ไม่ใช่แค่ผู้เล่นเดินเข้า Trigger
4. ทดลองเล่นแบบไม่วิ่ง ไม่สำรวจเส้นรอง ยิงพลาดทั้งหมด และกระเป๋าเต็ม เพื่อหา Softlock
5. จึงเพิ่มต้นไม้ หมอก วัสดุ เสียง และรายละเอียดบ้าน

ถือว่ารุ่นแรกผ่านเมื่อผู้เล่นใหม่หาเข้าบ้านได้ เก็บของและเลือกอาวุธเองได้ เติมกระสุนได้ และกลับมาฝึกต่อได้แม้ยิงพลาด โดยไม่ต้องมีผู้พัฒนาชี้ทางตลอดเวลา เอกสารนี้เป็นข้อเสนอออกแบบ ยังไม่ได้แก้ Scene หรือเพิ่มระบบ Tutorial
