# Dev Log — 18 ตุลาคม 2026

## เป้าหมายและผลลัพธ์
ทำให้ศัตรูกดดันต่อเนื่องโดยยังควบคุมจำนวนผู้เข้าทำ แยกสิทธิ์เคลื่อนที่กับสิทธิ์โจมตี และลดกฎ Escape ที่ผ่อนทั้งฝูงจนผู้เล่นเดินหรือวิ่งหลบได้ง่ายเกินไป การยิงปกติคง physical feedback แต่ไม่ยกเลิก action ทุกนัด ใช้ impact สะสมและ Critical Break เป็นโอกาสสร้างพื้นที่แทน รายละเอียดอยู่ใน EnemyActionBreak.md และ EnemyCombatFlow.md

Charge เป็นพฤติกรรมของแต่ละตัว ใช้สิทธิ์และเวลาร่วมของกลุ่มกำกับการเริ่ม เมื่อโดนสามารถเรียก event/ล็อกผู้เล่นและกันการโจมตีซ้อนชั่วคราว เอกสารและแผนภาพแยกวงจรให้ตรวจง่ายขึ้น

## ผลทดสอบกับผู้ใช้
ผู้ใช้รายงานว่าศัตรูหนึ่งตัวรับมือได้ง่าย ส่วนสองตัวเริ่มตึงมือ ถือเป็นฐานสำหรับทดสอบ encounter ต่อ ยังไม่สรุปสมดุลสุดท้าย จำนวนฝูงทั้งหมดและจำนวนผู้เข้าทำพร้อมกันควบคุมแยกกันได้ ฉากฝูงอาจใช้เพื่อหนีหรือสู้ตามบริบท ไม่เปลี่ยนทุกฉากให้เป็นเหตุการณ์หนี

วิเคราะห์คลิปการโจมตีพบว่ามีทั้งการทำ damage สำเร็จและการเดินหลบก่อนจังหวะตรวจโดน ปัจจุบัน melee ตรวจครั้งเดียวหลัง windup และใช้ระยะ root-to-root ร่วมกับมุมและสายตา เพิ่มวงระยะ/มุมใน Gameplay ให้เทียบภาพได้ก่อน ไม่ปรับ Range หรือสร้าง hit window ใหม่โดยพลการ

## เครื่องมือและการใช้งาน
เพิ่ม HUD ที่แก้ Prefab ได้ เครื่องมือ Cheat/ตั้งค่าที่จัดเป็นหมวด และข้อมูล debug สิทธิ์/impact/แหล่งเกิด ปรับการเกิดลับสายตาและการแสดงโมเดลนอกกล้อง แต่ยังไม่อ้างว่าพิสูจน์สาเหตุ pop-in เก่าครบทุกกรณี

งานล่าสุดรวมทางสร้าง Patrol Route จาก Spawn Inspector และเมนูที่เลือก Spawn Point ให้ใช้ helper เดียวกัน สร้างเป็น child ของ Spawn Point และ assign ให้ พร้อม Undo และบันทึก prefab reference override จุด Shift-click ยังคงอยู่ใต้ Route และกำหนดตำแหน่งโลกตามที่คลิก ไม่ย้าย Route เดิมที่อาจใช้ร่วมกัน
