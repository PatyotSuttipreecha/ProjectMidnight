# Dev Log — 2 พฤศจิกายน 2026

## ปัญหาที่แก้
Hierarchy เดิมมีการตั้งสีที่เข้าถึงยาก สีจาง ข้อความ/ไอคอนวาดซ้อน จึงเปลี่ยนมาใช้ palette ที่เลือกได้โดยตรง คลังไอคอนค้นหาได้ และไม่วาดชื่อซ้ำ เพิ่มการตั้งสีลูกทั้งหมดพร้อม Undo และการไล่เฉดตามตัวอย่างที่ผู้ใช้ส่ง

Lighting รุ่นแรกแก้ค่าแล้วเห็นผลเฉพาะตอนเล่น ทำให้ออกแบบบรรยากาศยาก จึงเพิ่ม Live Preview ใน Editor และเครื่องมือเทียบ A/B, Duplicate และ Apply Initial ลงฉาก โดยแยกค่าทดลองจากค่าที่บันทึกจริง Preview คืนค่าก่อนบันทึกหรือเข้า Play เพื่อไม่ให้สำเนาชั่วคราวกลายเป็น reference ที่หายภายหลัง

## พฤติกรรมสุดท้ายของ Bounding
ผู้ใช้ต้องการขอบเขตเรียกแสงแยกจาก Trigger เดิม และแก้ความต้องการภายหลังให้เข้าแล้วเปลี่ยนค้าง จึงยกเลิกการคืนค่าเมื่อออก ใช้ Trigger Once ต่อรอบเล่นเป็นค่าเริ่มต้น การเปลี่ยนแสงภายหลังทำผ่าน Bounding ถัดไปหรือ LightingCue ได้ทันที ส่วน Local Volume ใช้ปรับเฉพาะบริเวณกล้องต่อไป

## Validation และขอบเขต
ตรวจ compile Runtime/Editor และ Lighting 34 checks ผ่าน มี regression ทดสอบการเดินย้อน การปิด/ลบ Bounding และ Cue ภายหลัง แก้ปัญหา Undo หลุดระหว่างสร้าง asset โดยย้ายการ record ค่าฉากไปหลัง import asset เครื่องมือไม่ rebake lighting และไม่มี Save/Load ทั้งเกม

รวมไฟล์งานอาร์ตที่ผู้ใช้ปรับไว้โดยไม่เขียนทับ เพิ่ม Git LFS ให้ไฟล์ต้นฉบับขนาดใหญ่ เฉพาะ commit ใหม่ ไม่ rewrite history รายละเอียดภาพรวมอยู่ใน Update-2026-11-02.md และวิธีใช้ระบบแสงอยู่ใน Lighting.md
