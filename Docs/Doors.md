# ระบบประตูและกุญแจ

เปิด `System Modification > Door Configuration` แล้วกด **สร้างประตู + กุญแจตัวอย่างในฉาก** ใน Edit Mode เครื่องมือสร้าง ItemSO, Pickup Prefab และ Door Prefab ใน `Assets/Prefab/Doors` พร้อมวางประตูใกล้ผู้เล่นและกุญแจอยู่ด้านหน้า จากนั้นบันทึกฉาก

## วิธีเล่น
เก็บกุญแจด้วยระบบ Pickup เดิม เล็งตรงกลางจอไปที่บานประตูและเข้าใกล้ แล้วกด E หากกุญแจไม่ตรงจะแสดง Requires การเปิด Inventory จะระงับการโต้ตอบประตู

## การตั้งค่า
- `Hinge`: Transform บานพับ วาง Mesh และ Collider บานประตูไว้ใต้ Transform นี้ มุมใน Edit Mode คือมุมปิด
- `Starts Locked` และ `Required Key`: ล็อกประตูและกำหนด ItemSO ชนิด Key; เปรียบเทียบ Asset โดยตรง ไม่ใช่ชื่อ
- `Consume Key`: ใช้แล้วลดจำนวนหนึ่งชิ้น มิฉะนั้นเก็บกุญแจไว้ใช้ประตูอื่นได้
- `Open After Unlock`: เปิดทันที หรือปลดล็อกก่อนแล้วกดอีกครั้งเพื่อเปิด
- `Open Rotation`: มุมหมุนจากตำแหน่งปิด เช่น Y 90 หรือ -90
- `Duration`: เวลาที่ใช้หมุนเต็มระยะ วินาที สามารถกดกลับทิศระหว่างหมุนได้
- `Interaction Distance`: ระยะจากตัวผู้เล่นถึงจุดที่เล็งบนบานประตู
- `Starts Open`: เริ่มเปิดได้เฉพาะประตูที่ไม่ล็อก
- `Audio Source` และเสียง Open / Close / Unlock / Locked: เสียงแต่ละการกระทำ
- `On Unlocked / On Opened / On Closed`: Event เมื่อเปลี่ยนสถานะเป้าหมาย การหมุนยังดำเนินต่อจนจบ

กุญแจใช้พื้นที่ Inventory ตาม Width/Height ของ ItemSO และรองรับ Examine / Drop ผ่านระบบเดิม ตัวอย่างเป็นทรงกล่องสำหรับเปลี่ยนโมเดลเองได้ Gizmos แสดงระยะโต้ตอบและแนวเปิด

ประตูล็อกที่ไม่มี Required Key จะเปิดไม่ได้ สถานะปลดล็อกอยู่ระหว่างการเล่นเท่านั้น ยังไม่มี Save/Load, การเปลี่ยนฉาก, ระบบตรวจสิ่งกีดขวางระหว่างหมุน หรือ Animator เฉพาะทาง การหมุนบานประตูใช้ Transform แบบ smooth interpolation

หลีกเลี่ยงวาง Pickup ที่รับ E ติดหน้าประตู เนื่องจากระบบ Pickup และ Door ยังรับปุ่มแยกกัน

## การตรวจสอบ
คอมไพล์ Runtime/Editor ผ่าน ทดสอบ Inventory core พร้อมกุญแจ: ไม่มี/ผิดกุญแจ, กุญแจใช้ซ้ำ, ลดทีละชิ้น, คืนพื้นที่เมื่อใช้ชิ้นสุดท้าย และแจ้ง UI ผ่าน ยังไม่ได้ทดสอบกล้อง/Collider/เสียงและตัวอย่างที่สร้างใน Playground Play Mode

## ประตูสองบาน / หลายบาน
กด **สร้างประตูสองบาน + กุญแจตัวอย่างในฉาก** ใน Door Configuration เพื่อสร้าง Prefab ตัวอย่างสองบานเปิดสวนทางกัน
สำหรับโมเดลของตนเอง เพิ่มรายการ `Leaves` ใน DoorController แล้วกำหนด Hinge และ Open Rotation ของแต่ละบาน (เช่น Y 90 และ -90) ใส่ Mesh/Collider ไว้ใต้ Hinge แต่ละตัว โดยมี DoorController เดียวที่รากร่วมกัน เล็งบานไหนก็สั่งเปิดทั้งชุด ใช้กุญแจเพียงครั้งเดียวและใช้เสียง/Events ร่วมกัน
หาก Leaves ว่างจะใช้ Hinge / Open Rotation เดิม จึงรองรับประตูบานเดียวเดิมได้ รายการที่มี Hinge ว่างหรือซ้ำจะไม่ทำงานและแจ้งข้อผิดพลาด มุมปิดอ้างอิงจาก localRotation เมื่อเริ่มเล่น

อัปเดต Interaction กลาง: ใช้ F ผ่าน PlayerInteraction แทนปุ่มรายวัตถุเดิม ดู Docs/Interaction.md สำหรับระยะ การเลือกเป้าหมาย และ UI prompt
