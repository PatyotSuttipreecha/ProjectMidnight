# รายการอัปเดต 16 ตุลาคม 2026

## Enemy และการกดดันผู้เล่น
- เพิ่ม Shared Combat Settings ใช้ร่วมกันตามผู้เล่นเป้าหมายข้าม Profile, Enemy Group และ Spawn Point พร้อมหน้าตั้งค่าที่ System Modification → Enemy Lab → Shared Combat Settings
- แยกสิทธิ์กลุ่มกดดันออกจากสิทธิ์โจมตี ตั้งต้นเจ้าของสิทธิ์กดดัน 3 ตัว ระยะเข้ากลุ่ม 4.5 เมตร และช่วงเว้นเริ่มโจมตี 0.8 วินาที
- ระยะแรกศัตรูไกลที่ตรวจพบผู้เล่นวิ่งเข้าหาได้ เมื่อกลุ่มกดดันครบ ตัวอื่นชะลอและรอรอบนอก เจ้าของเดิมถือสิทธิ์ผ่านการเดินวน เตรียมโจมตี โจมตี และ Recovery
- เมื่อถูกขัดจังหวะ ตาย Pause หรือไล่ติดทาง คืนเฉพาะช่องที่ว่าง เลือกตัวแทนใกล้ที่สุดที่มีเส้นทางเดินถึง และเติมทีละตัวห่างกัน 0.6 วินาที ไม่เปิดระลอกใหม่เพียงเพราะยิงหนึ่งตัว
- ระหว่างผู้เล่นวิ่งหนี ศัตรูเข้า EscapeWalk และยังเดินตามด้วย Walk Speed ของ Profile แต่พัก Rush การเริ่มโจมตีใหม่และการแจกสิทธิ์ ตัวที่เริ่มท่าโจมตีไปแล้วสามารถจบท่าได้
- ตรวจหนีจากการวิ่งและความเร็วจริง ตัวขวางด้านหน้าไม่บดบังผู้ไล่ด้านหลัง และการวิ่งเปลี่ยนทิศไม่เปิด Rush กลับทันที
- หลังหยุดวิ่งครบ Escape Resume Delay (ตั้งต้น 0.8 วินาที) ล้างสิทธิ์ชุดเดิมของเป้าหมายนั้นและเริ่มรอบเข้าหาใหม่ แจกสิทธิ์ตามระยะใหม่ ไม่สืบทอดเจ้าของรอบก่อน
- เก็บการตั้งค่า Walk/Boost เดิมไว้สำหรับกลับไปใช้เมื่อปิด Use Rush Slots

## Spawn และเครื่องมือ Debug
- Enemy Spawn Point รองรับ Single และ Random Prefab Pool เลือกหลาย Prefab และรับ Profile/อาวุธจากตัวที่สุ่มได้ ข้ามรายการว่างหรือไม่มี Profile
- ปรับป้าย State ใน Gameplay ให้กระชับ มีหมายเลขประจำตัว จุดและเส้นเชื่อมกับศีรษะ พร้อมรายละเอียดตัวที่โฟกัส แสดงใกล้ก่อนและจำกัดจำนวนป้าย
- เพิ่มค่าปรับจำนวนป้าย ระยะ ขนาดข้อความและระยะเหนือศีรษะใน Cheat Menu พร้อมข้อมูลกลุ่มกดดันและช่วงหนี

## ฉาก เอกสาร และแผนภาพ
- รวม Torch Prefab และการปรับ Scenes_Gameplay, Playground, Timeline และ NavMesh ที่อยู่ใน workspace พร้อม meta
- เพิ่ม TheLost-RushPressure.drawio พร้อม SVG/PNG และหน้า 05 — Rush & Pressure ใน TheLost-Behavior.drawio
- อัปเดตคู่มือ Enemy Group Combat, Enemy Lab และ Enemy Spawning ให้ตรงกับวงจรล่าสุด

## การตรวจสอบ
- Runtime และ Editor คอมไพล์ผ่าน มี warning เดิมของโปรเจกต์
- ชุดทดสอบ Unity Play Mode แยกผ่าน 234 checks ใช้ AI, NavMesh, locomotion, โมดูลอาวุธ, projectile และ effects จริง โดยใช้ PlayerController จำลองสำหรับเลือดและสัญญาณการวิ่ง
- ครอบคลุมการคงสิทธิ์ระหว่างโจมตี การเลือกตัวแทนใกล้ การเติมเหลื่อมเวลา การเดินตามระหว่างหนี การล้างสิทธิ์หลังหนี และการรับสิทธิ์รอบใหม่
- ยังต้องประเมินความยาก แอนิเมชันและสมดุลฝูงจากการเล่น Scenes_Gameplay จริง ผลทดสอบแยกไม่ยืนยันภาพและสมดุลของฉากทั้งหมด
