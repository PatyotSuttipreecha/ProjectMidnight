# การเข้าประชิดและแบ่งจังหวะโจมตีของ Enemy

> ลำดับปัจจุบันหลังลดเงื่อนไขซ้อน: [EnemyCombatFlow.md](EnemyCombatFlow.md) และ [Draw.io](Design/Enemy-Combat-Simplified.drawio) ระบบใช้ Combat Turn ชุดเดียวสำหรับการเข้าทำ ส่วน Movement Slot คุมการเคลื่อนที่ เนื้อหาการปรับก่อนหน้านี้ด้านล่างเป็นประวัติและรายละเอียดประกอบ

## เป้าหมายในการออกแบบ
ระบบเดิมต่างกันที่ตำแหน่งปลายทางและการหลบกัน แต่ทุกตัวยังมีเหตุผลเดียวคือเดินเข้าระยะแล้วตี การเพิ่มความสุ่มอย่างเดียวจึงไม่แก้พฤติกรรมของฝูง แนวทางใหม่นี้แยกการเลือกวิธีเข้าหาของแต่ละตัวออกจากการจัดสิทธิ์โจมตีของกลุ่ม เพื่อให้เกิดทั้งความหลากหลายและช่องว่างที่ผู้เล่นอ่านสถานการณ์ได้

## การเลือกวิธีเข้าหา
- Direct: เดินกดดัน ใช้ Pressure Speed Multiplier ปรับความเร็วไล่ช่วงที่ยังอยู่นอกระยะชะลอ
- Flank: เข้าด้านข้างตาม Flank Angle โดยคำนวณจากฝั่งที่ศัตรูอยู่ตอนเลือกวิธี ตรวจ NavMesh และ path ก่อนใช้จุดใหม่
- Burst: เร่งเข้าหาตาม Burst Speed Multiplier ในช่วงไกล แล้วชะลอตามระบบเดิมเมื่อเข้าใกล้

เลือกเฉพาะช่วงเห็นผู้เล่นและยังไม่โจมตี ใช้ Direct / Flank / Burst Weights เป็นน้ำหนักสัมพัทธ์ เช่น 1/1/0.6 หมายถึง Burst มีโอกาสน้อยกว่าสองวิธีแรก ทุกค่าเป็นศูนย์ใช้ Direct การตัดสินใจยึดไว้ตาม Decision Interval ไม่สุ่มทุกเฟรม และไม่เปลี่ยนวิธีระหว่างท่าโจมตี

ตอนมองไม่เห็นใช้ตำแหน่งล่าสุดที่เห็นและวงจร Search เดิม ไม่มีการรู้ตำแหน่งผู้เล่นจากข้อมูลของเพื่อนอัตโนมัติ

## การตัดสินใจร่วมกัน
EnemyAttackCoordinator เก็บ reservation แยกตาม target ของ PlayerController จริง โดยมีจำนวนจำกัดตาม Maximum Reserved Attackers

1. ศัตรูที่เห็นผู้เล่น อยู่ใน Engagement Distance ไม่ติด cooldown และพ้นช่วงพัก ขอสิทธิ์เข้าประชิด
2. ตัวได้สิทธิ์เข้าไปโจมตี ส่วนตัวที่ไม่ได้สิทธิ์อยู่ในสถานะ Pressure และหาจุดบนวง Pressure Ring นอก Attack Range
3. สิทธิ์ครอบคลุมการเข้าหา การเตรียมโจมตี hit delay และ cooldown recovery ตัวที่จองอยู่จึงไม่เปิดช่องให้ทั้งฝูงตีทับกัน
4. เมื่อโจมตีจบ ถูกยิงเสียจังหวะ Pause ตาย หรือ Disable จะคืนสิทธิ์ และพักตาม Rest Before Next Turn ก่อนขอใหม่
5. หากจองแล้วเข้าไม่ถึงภายใน Attack Turn Timeout จะคืนสิทธิ์ ป้องกันตัวติดทางตันครองสิทธิ์ตลอด
6. Reservation ที่หยุดอัปเดตมีเวลาหมดอายุ และข้อมูล static ล้างเมื่อเริ่ม Play ใหม่เพื่อรองรับการปิด Domain Reload

ตัวที่ไม่ได้สิทธิ์ยังหลบและแยกจากเพื่อนด้วย Crowd Separation เดิม หากจุดวงกดดันไม่มี path จะรอในจุดที่ไปถึงได้ ไม่ผลักผ่านผนังและไม่เร่งเข้าตีแทนเอง ระบบยังไม่มีคิวที่รับประกันลำดับก่อนหลังแบบ FIFO การพักหลังจบและ timeout ช่วยเปิดโอกาสให้ตัวอื่น และยังต้องปรับจาก playtest ฝูงจริง

## วิธีตั้งค่า
เปิด Enemy Profile หรือ Enemy Lab แล้วดู Approach Decisions และ Group Engagement ทุกช่องมี Tooltip ภาษาอังกฤษ

ค่าตั้งต้นสำหรับลองฝูงเล็ก:
- Use Approach Decisions: เปิด
- Decision Interval: 2.5 วินาที
- Direct / Flank / Burst Weights: 1 / 1 / 0.6
- Flank Angle: 40 องศา
- Pressure Speed Multiplier: 0.7
- Burst Speed Multiplier: 1.25
- Coordinate Attacks: เปิด
- Maximum Reserved Attackers: 1 เพื่ออ่านจังหวะง่าย; 2 เพื่อเพิ่มแรงกดดัน
- Engagement Distance: 6 หน่วย
- Pressure Ring Radius: 3.5 หน่วย ระบบบังคับให้อยู่นอก Attack Range
- Attack Turn Timeout: 4 วินาที
- Rest Before Next Turn: 1 วินาที

ใช้ limit เดียวกันสำหรับ profiles ที่เจอผู้เล่นใน encounter เดียวกัน หากใช้ต่างกัน ผู้ขอใหม่จะใช้ค่าจำกัดที่เข้มกว่าของ reservation ที่มีอยู่ แต่จะไม่ยกเลิกท่าโจมตีที่เริ่มแล้วเพื่อบังคับ limit ใหม่

ปิด Coordinate Attacks เพื่อกลับไปให้ทุกตัวเข้าตีได้ตามวงจรเดิม ปิด Use Approach Decisions เพื่อไม่เปลี่ยนวิธี/ตัวคูณความเร็ว แต่ยังเปิดการประสานกลุ่มได้แยกกัน

## ขอบเขตของงาน
ยังใช้ท่าโจมตีและระบบ Damage เดิม ไม่ได้เพิ่มคลิปพุ่ง/จับหรือ Blend Tree ใหม่ Run Animation State ที่มีอยู่ใช้ได้กับความเร็วจริงของ Agent ท่าที่เห็นจึงขึ้นกับคลิปใน Animator ด้วย

## การทดสอบ
Compile Runtime/Editor ผ่าน ทดสอบ production EnemyController และ EnemyAttackCoordinator ใน Play Mode โปรเจกต์แยก 10 checks ครอบคลุมจำกัดผู้โจมตีหนึ่งตัว, Pressure, คืนสิทธิ์เมื่อถูกยิง, รับสิทธิ์ต่อ, target คนละตัวไม่แย่งกัน, การทำ Damage ด้วย coroutine ที่เดินตามเวลาจริง และการคืนสิทธิ์เมื่อ Pause โดย PlayerController ใช้ damage stub ยังไม่ได้ยืนยัน path/animation และสมดุลฝูงใน Scenes_Gameplay จริง

## Shared attack start timing

เพิ่ม EnemyCombatSettings ที่ Assets/Data/Enemies/Resources/EnemyCombatSettings.asset ตั้ง Attack Start Interval เริ่มต้น 0.8 วินาที เปิดได้จาก Enemy Lab → Profiles → Group → Open Shared Combat Timing ค่านี้ใช้ร่วมทุก Profile/Enemy Group แยกนาฬิกาตาม Player เป้าหมาย ก่อนเข้า Preparation ต้องจองเวลาเริ่มก่อน ตัวที่มีสิทธิ์ยังเข้า Approach ได้ แต่จะไม่เริ่มเตรียมโจมตีพร้อมกัน การยกเลิก/ปล่อยสิทธิ์ไม่ล้างช่วงเว้นนี้ เพื่อกันเริ่มซ้อนเฟรมเดียวกัน นาฬิกาใช้เวลาของเกมจึงหยุดตาม Time Scale; 0 ปิดการเว้นสำหรับรอบใหม่ ค่าที่จองไปแล้วจะหมดตามเวลาเดิม

ตั้ง TheLost ทั้งหก Profile ให้ Max Concurrent Attackers = 2 เพื่อทดลองร่วมกัน ค่านี้ยังเป็นเพดานสิทธิ์ตามระบบเดิม Attack Turn Rest เป็นเวลาพักรายตัวไม่ใช่ช่วงเว้นส่วนกลาง การเริ่มเหลื่อมไม่รับประกันว่า Damage จะเข้าเหลื่อมเมื่อ Windup ของอาวุธต่างกัน

## Rush Slots — กลุ่มกดดันและจังหวะให้ผู้เล่นหนี

การปรับรอบนี้เปลี่ยน Rush Slot จากสิทธิ์วิ่งช่วงไกลให้เป็น **สิทธิ์ประจำกลุ่มกดดัน** เมื่อเดินเข้าถึงผู้เล่นจะยังรักษาสิทธิ์ไว้ ทั้งช่วงเดินวน เตรียมโจมตี โจมตี และพักหลังโจมตี จึงไม่คืนช่องให้ศัตรูอีกสามตัววิ่งเข้ามาเพียงเพราะชุดแรกเข้าประชิดแล้ว

สิทธิ์นี้ใช้ร่วมกันทุก Profile, Enemy Group และ Spawn Point ที่มี Player เป้าหมายเดียวกัน แยกจาก Attack Turns: มีผู้ครองกลุ่มกดดัน 3 ตัวได้ แต่ผู้เริ่มโจมตียังต้องผ่านเพดาน Attack Turns และ Attack Start Interval ตามเดิม กลุ่มกดดันมีหน้าที่คุมจำนวนคนที่เร่งไล่และการเติมตัวแทน ส่วนสิทธิ์โจมตีมีหน้าที่คุมจังหวะลงมือ

### 1. เข้าหาครั้งแรกและตั้งกลุ่ม

- เมื่อยืนยันเป้าหมาย สุ่มความพร้อมที่จะวิ่งครั้งเดียวต่อศัตรูต่อรอบตาม Approach Run Chance (เริ่มต้น 55%) ตัวที่ไม่เลือกวิ่งยังเดินตาม ไม่สุ่มสลับเดิน/วิ่งทุกเฟรม
- สุ่มเลือกจากผู้ที่พร้อมวิ่งและมีเส้นทางถึง แล้วให้ออกตัวทีละคนตาม Rush Start Delay (เริ่มต้น 0.3–0.7 วินาที) โดยจำนวนเจ้าของสิทธิ์กดดันรวมกับผู้วิ่งเข้ามาที่กำลังรอรับสิทธิ์ไม่เกิน Max Rushers (เริ่มต้น 3 ตัว)
- ตัวที่เข้าใกล้ถึง Pressure Distance (เริ่มต้น 4.5 เมตร) ก่อนมีสิทธิ์เข้ากลุ่มก่อน ไม่ว่าจะเดินหรือวิ่งเข้ามา การสุ่มให้วิ่งไม่ใช่การจองสิทธิ์กดดัน หากถึงในเฟรมเดียวกันใช้ตัวใกล้ก่อนเป็นตัวตัดสิน
- เมื่อกลุ่มเต็ม ระบบจำว่าตั้งกลุ่มสำเร็จแล้ว ตัวอื่นจะชะลอเป็นเดินและรอด้านนอกระยะกดดัน
- ผู้ครองสิทธิ์ยังตามและวิ่งเมื่ออยู่ไกลได้ แต่ชะลอ/เดินวน/โจมตีตามระยะและเงื่อนไขเดิม การถึงตัวผู้เล่นหรือเริ่มโจมตี **ไม่คืนสิทธิ์กดดัน**

ตัวที่เดินเข้าถึงก่อนสามารถรับสิทธิ์แทนผู้วิ่งที่ยังมาไม่ถึงได้ หากจำนวนรวมเกินโควตาจะชะลอผู้วิ่งที่ไกลที่สุดลงเป็นเดินโดยไม่ลงโทษ cooldown ใช้กติกาเดียวกันทั้งครั้งแรกและรอบใหม่หลังหนี ตั้งโอกาสเป็น 0 เพื่อให้ทุกตัวเดิน หรือ 1 เพื่อให้ทุกตัวพร้อมถูกเลือกวิ่ง แต่ยังจำกัดจำนวนและออกตัวเหลื่อมกัน หากสุ่มแล้วไม่มีใครเลือกวิ่ง ทั้งฝูงจะเดินเข้ามาได้ตามปกติ

### 2. ถูกขัดจังหวะและรับช่วงต่อ

คืนสิทธิ์เฉพาะตัวที่ถูกขัดจังหวะ ถูก Pause เสียเป้าหมาย เดินตามไม่ได้ ตาย หรือถูกปิดใช้งาน ส่วนตัวที่เหลือยังถือสิทธิ์เดิม และกลุ่มยังอยู่ในสถานะที่ตั้งสำเร็จแล้ว การยิงหนึ่งตัวจึงไม่เปิดโหมดวิ่งเข้าหาพร้อมกันทั้งฝูงอีกครั้ง

หลังพ้น Replacement Interval (0.6 วินาที) ให้ตัวที่เข้าถึง Pressure Distance และมีเส้นทางถึงก่อนรับช่วง **ครั้งละหนึ่งตำแหน่ง** โดยบันทึกลำดับเข้าระยะระหว่างรอด้วย ผู้วิ่งที่ยังอยู่ไกลไม่มีสิทธิ์กดดันล่วงหน้า ระหว่างมีช่องว่างจะเลือกผู้วิ่งแบบสุ่มและออกตัวเหลื่อมกันภายในโควตาเดิม หากหลายตำแหน่งว่างจะรับสมาชิกเหลื่อมตาม Replacement Interval ตัวที่เพิ่งเสียสิทธิ์ต้องพัก Rush Reentry Delay (2 วินาที) ก่อนกลับเข้าเป็นผู้สมัคร

Rush Stall Timeout (2 วินาที) ตรวจการไม่คืบหน้าเฉพาะตอนกำลังไล่จากระยะไกล การเดินวน เตรียมโจมตี โจมตี พักหลังโจมตี และพักช่วงผู้เล่นวิ่งหนีไม่ถูกนับเป็นการติดทางโดยอัตโนมัติ

### 3. เปิดจังหวะให้ผู้เล่นวิ่งหนี

เมื่อเปิด Pause Rush While Escaping ระบบตรวจการวิ่งจริงที่กำลังเคลื่อนออกห่างจากศัตรูซึ่งร่วมไล่อยู่ โดยตัวที่อยู่ข้างหน้าจะไม่บังเงื่อนไขของผู้ไล่ด้านหลัง เมื่อเริ่มหนีแล้วจะคงช่วงพักตลอดการวิ่งจริง แม้หันหรือวิ่งหลบไปมา ไม่ใช้แค่การกดปุ่มวิ่งค้าง

ระหว่างหนีและช่วงรอหลังหนี:

- ศัตรูที่ยังไม่เริ่มท่าโจมตีเข้า EscapeWalk และเดินตามด้วย Walk Speed ของ Profile รวมถึงตัวที่มีสิทธิ์วิ่งหรือโจมตีอยู่ ไม่หยุดยืนนิ่งและไม่เร่งเป็น Rush
- คืน Attack Turn และไม่เริ่มโจมตีใหม่ระหว่างพัก แต่ยังถือสิทธิ์กลุ่มกดดันของตัวเดิมไว้
- หยุดให้สิทธิ์ใหม่และหยุดเติมตัวแทนชั่วคราว
- เก็บสิทธิ์ของเจ้าของเดิมไว้ ไม่ทำให้ทั้งกลุ่มเริ่มใหม่ทุกครั้งที่กดวิ่ง
- การโจมตีระยะใกล้ที่กำลังเกิดยังทำงานได้ ช่วงหนีจึงไม่ใช่ช่วงอมตะ

เมื่อผู้เล่นหยุดวิ่งจริง ให้รอ Escape Resume Delay (0.8 วินาที) ระหว่างรอยังเดินตาม หากกลับไปวิ่งระหว่างนี้จะเริ่มรอใหม่ เมื่อครบเวลาล้างเจ้าของสิทธิ์ ผู้วิ่ง ลำดับเข้าระยะ และผลสุ่มเดิมเฉพาะเป้าหมายนี้ เริ่มสุ่มเลือกผู้วิ่งและออกตัวเหลื่อมกันใหม่ ก่อนแจกสิทธิ์กดดันตามลำดับที่เข้าถึง Pressure Distance จนครบ Max Rushers ไม่สืบทอดสิทธิ์จากรอบก่อน ตัวที่ยังอยู่ใกล้อาจได้รับสิทธิ์ใหม่ทันทีตามระยะจริง

การล้างรอบจากการหนีไม่ใช่การถูกขัดจังหวะ จึงไม่เพิ่ม Rush Reentry Delay ให้เจ้าของเดิม แต่ไม่ลบ cooldown ที่ยังเหลือจากการถูกยิง และไม่ยกเลิกท่าโจมตีที่เริ่มไปแล้ว ไม่กระทบกลุ่มที่ไล่เป้าหมายอื่น การเสียเจ้าของเพียงหนึ่งตัวระหว่างต่อสู้ตามปกติยังเติมเฉพาะช่องที่ว่างเช่นเดิม

## Pressure หลังถูกยิง
Bullet hit ยังคงปล่อย pressure ownership / attack turn และให้คนอื่นแทนตามปกติ
เมื่อฟื้นจาก stagger แล้วเข้า Pressure จะจำรัศมีปัจจุบันสำหรับวงรอรอบนั้น (ไม่เกินวงที่ตั้งไว้ และไม่ต่ำกว่าระยะเคลียร์ตัว)
จึงไม่สั่งให้เดินถอยไปวงรอด้านนอกเพียงเพราะเสียสิทธิ์; ยังคงหันมองและเดินวนใกล้ตำแหน่งฟื้นตัว
ออกจาก Pressure แล้วเข้ารอบใหม่จะคำนวณรัศมีใหม่ ไม่ล็อกตำแหน่งโลกและไม่ข้าม cooldown
แรง knockback จากกระสุนและการเว้นระยะป้องกันตัวซ้อนกันยังทำงานตามเดิม

## เดินหนีและส่งต่อสิทธิ์ (Pressure handoff)
ไม่เปลี่ยนความเร็วผู้เล่น และไม่ถือว่าการเดินหนีเป็น sprint Escape
- คนถือ pressure slot ที่ยังไม่เริ่มโจมตีและอยู่นอกวงเข้าประชิดจะวัดระยะห่าง หากผู้เล่นเคลื่อนออกห่างต่อเนื่อง 2.5 วินาทีและช่องว่างเพิ่มอย่างน้อย 0.5 เมตร ให้คืนสิทธิ์
- หากช่องว่างคงเดิม ลดลง ผู้เล่นหยุด หรือมีการเตรียม/โจมตี/Charge/Recovery จะไม่ริบสิทธิ์ด้วยเงื่อนไขนี้
- ส่งต่อทีละคนตาม Replacement Interval; เจ้าของเดิมติด Rush Reentry Delay ไม่สุ่มกลุ่มใหม่
- ผู้เล่นเดินเข้าประชิดตัวรอที่มองเห็นและมีทางเข้าถึงได้: จัดตัวนั้นก่อนผู้รอทั่วไป และแทน pressure owner ที่ยังไม่เริ่มโจมตีและอยู่ไกล
- Attack turn ที่เป็นเพียงการเดินเข้าหาสามารถถูกส่งต่อให้ตัวประชิดได้ แต่ไม่แย่งจากท่าที่เริ่มแล้ว; จำนวนผู้โจมตีและ Attack Start Interval ยังบังคับเหมือนเดิม
- Pressure มีงบเดินถอยออกจากผู้เล่น 0.6 เมตรต่อรอบ จากนั้นหามุมด้านข้าง/หยุดเมื่อชิดระยะเคลียร์ตัว ไม่รักษาวงด้วยการเดินถอยอย่างไม่สิ้นสุด
ตั้งค่า: Enemy Lab > Open Shared Combat > Pressure > Pressure handoff
Growing-gap duration (s), Minimum gap growth (m), Pressure backstep budget (m)

## Front interception: ให้สิทธิ์ก่อนถึงระยะตี
ใช้ทิศทางการเคลื่อนที่จริงของผู้เล่น ทั้งเดินและ sprint ไม่ใช้ทิศกล้อง
ตัวที่มองเห็นผู้เล่น อยู่ในกรวยด้านหน้า 100 องศา ระยะไม่เกิน 6 เมตร และมี NavMesh path ถึงผู้เล่นครบ จะเป็นผู้สมัครสวนเข้าประชิด
เลือกตัวใกล้ที่สุดก่อน ให้สิทธิ์ทีละตัวตาม Replacement Interval; ถ้าเต็ม ส่งต่อจากเจ้าของด้านหลังที่ยังไม่เริ่มโจมตีและไม่ได้อยู่ระยะตี
ไม่รอให้ผู้เล่นชนถึง melee range และไม่ต้องรอ growing-gap timer กรณีนี้
ผู้รับสิทธิ์เข้าประชิด/วิ่งสวนได้ระหว่าง Escape pause และขอ attack turn จากตัวที่ยังเดินเข้าหาจากด้านหลังได้ แต่ไม่ขัดการโจมตีที่เริ่มแล้ว
เมื่อผู้เล่นผ่านไปแล้วจนศัตรูหลุดกรวยด้านหน้า ข้อยกเว้นการวิ่งสวนหมดลงทันที กลับเดินตามช่วง Escape ตามเดิม
ตั้งค่า Shared Combat > Pressure > Front interception: Front opportunity range (m), Movement cone angle
ยังบังคับ shared pressure/running cap, concurrent attack turns, start interval, hit protection และ reentry cooldown เหมือนเดิม

ตรวจสอบ Front interception: Runtime/Editor compile ผ่าน และ Unity Play Mode แยก 274 checks ผ่าน (production AI/NavMesh/effects, PlayerController damage/input stub) รวมรับสิทธิ์ด้านหน้าก่อนระยะตี ไม่เกิน cap วิ่งผ่านแล้วหยุดไล่เร็ว และไม่แย่งจากการโจมตีที่เริ่มแล้ว

## ความเร็วเข้าประชิดใน Shared Combat
ตัวที่ได้สิทธิ์วิ่ง: นอก Chase Slowdown Distance ใช้ Chase Speed × Burst Speed Multiplier
เข้าเขตชะลอแล้วและมี pressure ownership หรือ attack turn: รักษา Close Approach Speed คงที่จนเริ่มเตรียมโจมตี ไม่ blend ผ่าน Patrol Walk Speed อีก
ตัวอย่างค่าปัจจุบัน Machete/Torch: นอก 4 ม. ใช้ประมาณ 3 m/s; ใน 4 ม. จนถึงระยะตีใช้ 2.3 m/s; เริ่ม Preparation จึงหยุด
การเปลี่ยนความเร็วของผู้ได้รับสิทธิ์ใช้ Speed Change Rate และ NavMesh acceleration; ค่าที่กล่าวเป็นความเร็วเป้าหมาย ไม่รับประกันความเร็วจริงเมื่อมีสิ่งกีดขวางหรือฝูงชน
คนยังไม่ได้สิทธิ์ใช้ Walk Speed ตามเดิม และ Pressure ยังคุมด้วย Pressure Orbit Speed
Escape การเดินตาม/การวิ่งสวนด้านหน้า และ legacy Walk/Boost ที่ปิด Shared Combat ยังใช้กติกาเดิม

ตรวจสอบสูตร Close Approach รอบนี้: Runtime/Editor compile ผ่าน และชุด Unity Play Mode แยก 280 checks ผ่าน รวมความเร็ว boosted นอกเขต ค่าคงที่ที่ขอบ/กลาง/ใกล้ระยะตี และผู้รอไม่รับความเร็วเพิ่ม (PlayerController เป็น damage/input stub)

## แก้ P+ ค้าง Pressure เพราะขอ attack turn ไม่ถึง
กรณี Machete Engagement Distance = 2 m / Torch = 1.6 m แต่วง Pressure เริ่มราว 4 m ทำให้มี P+ แต่ไม่มี A+ แล้ววนอยู่นอกระยะขอสิทธิ์
Shared pressure owner จึงใช้ effective request range อย่างน้อย max(Pressure Distance, Chase Slowdown Distance, Pressure Ring Radius) + 0.5 m รวม reach และระยะ Charge ที่เกี่ยวข้อง
ยังคง concurrent attacker limit และ shared start interval; มีเฉพาะตัวที่รับ A+ เข้าทำการโจมตี คนอื่นยังรอ
Gameplay focus และ Inspector แสดง Effective turn request range / Target gate เพื่อเห็นเวลาที่ติดสิทธิ์หรือ hit protection

## Lost melee: ปิดระยะก่อนลงมือ
Machete/Torch เปิด Advance During Preparation: เดินปิดระยะด้วย Close Approach Speed ระหว่างช่วงเตรียม แล้วล็อกทิศที่เริ่ม windup
Melee Attack Step = 0.25 m: ก้าวสั้นไปทิศที่บันทึกไว้ระหว่าง windup ใช้ NavMesh path/ขอบเขตและระยะเคลียร์ตัว ไม่ตามผู้เล่นหลังเริ่มลงมือ
ตั้งใน Enemy Profile > Combat; ปิด advance หรือกำหนด step=0 เพื่อกลับไปใช้ท่าเตรียมหยุด/ไม่ก้าว
ค่าใหม่ default advance=false / step=0 เพื่อไม่เปลี่ยน heavy/ranged profile เดิม; เปิดเฉพาะ Machete/Torch ในรอบนี้; Stone หยุดเตรียมเสมอ
ระยะ hit, arc, line of sight, shared protection และเวลาจังหวะ animation จาก Weapon Module ยังคงใช้จริง ไม่ขยายระยะ damage เพื่อให้ตีโดน

ตรวจแก้ Pressure deadlock รอบล่าสุด: Runtime/Editor compile ผ่าน; Unity Play Mode แยก 287 checks ผ่าน
ทดสอบ production AI/NavMesh ด้วย request range 1.6 m เทียบวง 4 m, melee range 1.5 m, preparation 0.25 s, windup 0.5 s, agent radius 0.3 m / stopping distance 0.8 m
ยืนยันออกจาก Pressure รับ A+, เดินตีผู้เล่นยืน, ปิดระยะและตีผู้เล่นเดินตรงหนี 1 m/s โดยปิด Charge, และการหลบด้านข้างหลัง windup commitment ยังพลาดได้
PlayerController ใน harness เป็น damage/input stub; ยังต้องประเมินการหลบกันในฝูงและ animation กับฉากจริงอีกครั้ง
