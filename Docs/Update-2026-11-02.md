# รายการอัปเดต — 2 พฤศจิกายน 2026

## Midnight Hierarchy
- ติดตั้ง Embedded Editor Package ที่ Packages/com.midnight.hierarchy สำหรับ Unity 6000.2.4f1 โดยกู้ซอร์สต้นฉบับจากแชต Tools บนคลาวด์
- ตั้งสี ไอคอน Divider และ Palette จากหน้าต่าง Tools > Midnight > Hierarchy หรือ Alt-click ที่แถว Hierarchy
- เพิ่มคลังไอคอนแบบตารางพร้อมค้นหา ตรวจพบ 1,177 รายการใน Unity รุ่นนี้ รองรับ Texture ในโปรเจกต์และเลือกไอคอนให้ Palette
- ไอคอนแต่งแสดงแทนตำแหน่งไอคอน GameObject ด้านหน้าชื่อ ไม่แสดงซ้ำด้านขวา แก้ข้อความซ้อนโดยคงข้อความของ Unity ชั้นเดียว
- ตั้งสี Recursive ด้วย Alt ขณะเลือกสี หรือ Include Children รวมลูกที่ inactive รักษาไอคอนรายตัว และ Undo ครั้งเดียวคืนทั้งชุด
- เพิ่ม Gradient ไล่จางซ้ายไปขวา ปรับปลายสีและความเข้มของแถวลูกได้; ลูกใหม่ที่สร้างภายหลังยังไม่รับสี recursive อัตโนมัติ
- มี Component mini inspector, Active toggle, Object/Scene bookmarks และคีย์ลัด Navigation อยู่ในหน้าต่างแยก ไม่ใช่แถบฝังใน native Hierarchy

## Story Lighting
- เพิ่ม LightingPreset, SceneLightingController, LightingCue และติดตั้งใน Scenes_Gameplay พร้อม Initial จากแสงเดิม และ Evening/Dusk/Night/Dawn ตัวอย่าง
- เปลี่ยนแสงหลัก Ambient หมอก Skybox ที่ shader รองรับ และ Color Adjustments ผ่าน Event โดยไม่มีวงจรเวลาอัตโนมัติ
- Live Preview ใน Edit Mode พร้อมแก้ Preset ในหน้าต่างเดียวกัน คืนค่าฉากก่อน Save/เข้า Play/ปิดหน้าต่าง และใช้สำเนา Material/Profile ระหว่าง Preview
- Apply as Initial Lighting + Save Scene ทำให้แสงใน Editor และตอนเริ่มเล่นตรงกัน สร้าง Skybox/Profile อิสระ รองรับ Undo การเปลี่ยนค่าฉาก
- เพิ่ม Duplicate/Save As, Compare A/B, Diagnostics สำหรับ Scene View/กล้อง/Volume masks/priority/แสง baked และรายการจัดการพื้นที่
- สร้าง Local Box Volume พร้อม Profile แยก ดูขอบเขตและระยะ Blend ได้ ใช้กับ Exposure/สีเฉพาะกล้อง ไม่เปลี่ยนแสงอาทิตย์เฉพาะกล่อง
- Lighting Bounding เป็นขอบเขตอิสระ ไม่ต้องมี WorldTrigger/PointNote/Collider/Rigidbody รองรับหมุนและ scale
- Bounding เปลี่ยนแสงหลักค้างหลังออกจากพื้นที่ เปิด Trigger Once เป็นค่าเริ่มต้นเพื่อไม่ย้อนแสงเมื่อเดินกลับ Priority ตัดสินกรณีเข้าหลายกล่องพร้อมกัน Cue ใหม่ยังสั่งเปลี่ยนต่อได้
- การเปลี่ยนค้างเป็นสถานะในรอบเล่น ยังไม่เชื่อม Save/Load และไม่ rebake lightmaps/probes

## การตรวจสอบ
- Runtime และ Editor compile ผ่าน Unity 6000.2.4f1 compiler
- Lighting ผ่าน 34 checks ใน Unity โปรเจกต์แยก รวม Edit Mode preview, asset isolation, duplicate, initial commit/Undo, URP local-volume blending, transition และ Bounding แบบเปลี่ยนค้าง
- Hierarchy ตรวจ catalog/โหลดไอคอน, recursive colors รวม Undo/Redo และ gradient ในโปรเจกต์แยก ไม่ใช่ผลรับรอง UX/ประสิทธิภาพในทุกฉาก
- ยังต้องตรวจแสง/ภาพจริงของด่าน โดยเฉพาะแสง baked, Reflection/Light Probes และความมืดขณะต่อสู้
