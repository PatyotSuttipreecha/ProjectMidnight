# Dev Log — 16 ตุลาคม 2026

## ปัญหาและเป้าหมาย
Rush Slot เดิมคืนสิทธิ์เมื่อเข้าระยะใกล้หรือเริ่มโจมตี ทำให้มีศัตรูวิ่งเติมเข้ามาตลอด ทั้งที่ชุดเดิมยังกดดันผู้เล่นอยู่ ต้องการคุมจำนวนผู้เข้ากดดัน เปิดโอกาสวิ่งหนี และเริ่มแจกสิทธิ์ใหม่หลังหนี

## แนวทางและผลลัพธ์
แยกการเป็นเจ้าของกลุ่มกดดัน การอนุญาตให้วิ่ง และสิทธิ์โจมตีออกจากกัน เจ้าของกลุ่มถือสิทธิ์ผ่านช่วงต่อสู้ทั้งหมด ส่วนการถูกขัดจังหวะหรือตายเปิดเพียงช่องที่ว่างให้ตัวใกล้และเดินถึงได้เข้ามาแทนทีละตัว ค่าการทำงานร่วมกันอยู่ใน EnemyCombatSettings SO และเปิดแก้ผ่านหน้าต่าง Editor โดยตรง

หลังทดสอบกับผู้ใช้ ปรับความหมายของช่วงหนีให้เป็นการเดินตามด้วย Walk Speed ใช้ State EscapeWalk การหยุดยืนนิ่งไม่ใช่พฤติกรรมที่ต้องการ ช่วงนี้พักเฉพาะ Rush การเริ่มท่าใหม่และการเติมสิทธิ์ แต่ไม่ยกเลิกท่าที่เริ่มไปแล้ว

เมื่อหยุดวิ่งครบเวลาพัก ให้เริ่ม encounter รอบเข้าหาใหม่เสมอ ล้างสิทธิ์กลุ่มเก่าของเป้าหมายนั้นโดยไม่ลงโทษ reentry ให้เจ้าของเดิม ศัตรูไกลที่พร้อมไล่กลับมาวิ่งเข้าหา และรับสิทธิ์ใหม่เมื่อถึงระยะที่กำหนด ตัวที่อยู่ใกล้จึงอาจได้รับสิทธิ์ทันที ไม่จำเป็นต้องสืบทอดจากรอบก่อน ส่วน cooldown จากการถูกยิงยังคงอยู่

## งานร่วมในรอบอัปเดตนี้

- ปรับป้าย State ให้เชื่อมกลับไปยังตัวศัตรูที่เป็นเจ้าของได้ชัดขึ้น พร้อมค่าปรับใน Cheat Menu
- เพิ่ม/อัปเดต Flowchart แบบแก้ไขได้และเอกสารประกอบ โดยเก็บหน้าแผนภาพเดิมไว้
- รวม Torch Prefab และฉาก Timeline/NavMesh ที่แก้ใน workspace รอบนี้
- ตรวจเรื่องกล้องหมุนไม่ได้ใน Unity พบว่าหลัง Game view รับโฟกัส กล้องตอบสนองและค่าแกนหมุนเปลี่ยนตามเมาส์ จึงไม่ได้แก้สคริปต์กล้องจากการตรวจครั้งนั้น
