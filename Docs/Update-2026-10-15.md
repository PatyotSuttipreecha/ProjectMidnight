# รายการอัปเดต 15 ตุลาคม 2026

## Enemy และ Animation
- เชื่อม Blend Tree กับความเร็วเคลื่อนที่จริงของศัตรู แปลงเป็น Speed: Idle 0 / Walk 0.5 / Run 1 พร้อม Horizontal และ Verticle ตามทิศเคลื่อนที่เทียบตัวละคร
- ปรับลำดับ Controlling → EnemyType → WeaponType → Speed → Direction แก้ EnemyType ที่ใช้ Speed ผิด และส่ง WeaponType ตามโมดูลที่ถือ เมื่ออาวุธหลุดกลับ Unarm
- กิ่ง Log / Stone / Axe ที่ยังไม่มี Motion ใช้ท่า Unarm ชั่วคราว ส่วนศัตรูตระกูลอื่นยังไม่เปิดใช้งาน
- ใช้ความเร็วอ้างอิงจากค่าการเดินและไล่ล่าอัตโนมัติ พร้อมป้องกันการเดินช้าเพราะฝูงชนแล้ว Blend ค้างใกล้ Idle
- แก้การเลือกท่าโจมตีหลังอาวุธหลุด และเอา Any State ที่แทรกการเลือกท่าโดยสคริปต์ออก
- เพิ่มทิศเดินวน Pressure แบบ Random / Clockwise / CounterClockwise พร้อมระยะเวลาคงทิศสุ่ม
- แก้ Two Bone IK แขนทั้งสองใน Machete Prefab ที่ Root และ Tip อ้างกระดูกเดียวกัน
- เพิ่มค้นหา Enemy_GripPoint สำหรับแนบอาวุธ โดย explicit Weapon Anchor มีลำดับก่อน แล้ว fallback เป็นมือขวา/ตัวศัตรู ค่า Local Position / Euler Angles / Scale ของ Module อิงจากจุดแนบนี้
- แก้ Machete Profile ให้ใช้ Machete Module และ Machete Prefab ให้ใช้ Machete Profile

## เครื่องมือ Editor และ Debug
- รวมช่องตั้งค่า Enemy Lab / Profile / Standalone ให้ใช้การจัดหมวดและเงื่อนไขเดียวกัน มีค้นหา Advanced และคำอธิบายช่องที่ซ่อน
- เพิ่มข้อมูลสด AI / Animation / Parameter / ความเร็ว / เส้นทาง และเอกสารวิธีใช้ Enemy Lab
- เพิ่มแสดง State ของศัตรูใน Gameplay เปิดปิดได้ จัดลำดับใกล้ก่อนและลดการทับของป้าย
- แก้ Cheat Menu และ Player Configuration ให้รีเฟรช Health ระหว่าง Play Mode เพิ่มข้อมูล Damage / แหล่งการเปลี่ยน Health และเลือกบันทึก Console ได้
- ให้ผลโจมตีนับ Hit และเริ่ม protection/restraint เมื่อ Damage ลดเลือดจริง ป้องกัน Invalid Damage
- ขยาย Sync Selected Assets ให้รองรับ Animation, FBX และ main asset ชนิดอื่น พร้อมตั้งชื่อตามเส้นทางโฟลเดอร์และรายงานเหตุผลที่ข้าม
- ย้าย Door Configuration เข้า System Modification → Scene Configuration

## Asset และฉาก
- รวมการจัดโฟลเดอร์และปรับ Animation / FBX / Controller, ค่าของโมดูลอาวุธ, เอฟเฟกต์ไฟ, วัสดุ และฉากที่แก้ใน workspace รอบนี้ พร้อมไฟล์ meta

## การตรวจสอบและข้อจำกัด
- Runtime และ Editor คอมไพล์ผ่าน มี warning เดิมของโปรเจกต์
- ชุดทดสอบ Unity Play Mode แยกผ่าน 129 ข้อ สำหรับ AI, locomotion parameters, การเลือกอาวุธ, projectile และ effects โดยใช้ PlayerController จำลอง
- การเพิ่ม Enemy_GripPoint หลังชุดทดสอบดังกล่าวคอมไพล์ Runtime ผ่าน และตรวจจุดใน Prefab ว่าเป็นลูกมือขวา ยังไม่ได้ยืนยันตำแหน่งอาวุธด้วยภาพในฉากจริง
- ตรวจ reference ของ Machete ครบ Prefab → Profile → Module → Model
- ประเด็นยังค้าง: จุด Spawn ใน Scenes_Gameplay ใช้ Machete Prefab ร่วมกัน จึงรับ Profile และอาวุธเดียวกัน การแยก Torch/Machete เป็น Prefab Variant และผูกจุด Spawn ยังไม่ได้ทำ ห้ามถือว่าการเลือกชนิดศัตรูแต่ละจุดแก้ครบแล้ว
- ยังต้องตรวจความลื่น เท้าไถล IK และภาพเอฟเฟกต์ในฉากจริง
